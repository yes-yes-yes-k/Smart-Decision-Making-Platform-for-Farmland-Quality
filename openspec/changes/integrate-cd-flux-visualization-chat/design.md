# 设计

## Context

基线为 `5dbb9da`，调研见 [能力清单](../../../docs/cd-flux-chat-integration-investigation.md)。`query_cd` 目前只有通量不可用占位；`cd_flux.calculate` 会 commit；来源过滤在无地区条件时失效；业务表无年度/企业输入。原有 Cd 草稿、版本保护、HTTP/SSE 和显式保存机制可复用。

## Goals / Non-Goals

交付有真实来源、明确时期和覆盖的通量查询、独立试算及可下载图表，并扩展地区/年度/企业输入。范围与 proposal.md 一致；管理导入、业务重算继续为独立操作。

## Decisions

2026-11-10 第1阶段细化：物理表采用并行 `cd_flux_input_v2/cd_flux_output_v2`，旧表保留。输出通过输入外键继承来源/年度/地块/样点，以输入revision及公式版本唯一；当前查询排除过期修订。具体字段、单位条件、legacy复制和回滚规则以 stage-1-contract.md、stage-1-schema.sql 为准。旧常数2000在20cm、一年、容重g/cm³条件下换算成立，仍需区分历史原始单位未知与新版显式单位。

### 1. 统一查询范围，保留数据覆盖边界

范围对象包含 `region_type/region_id` 或 `parcel_id`、`source`、`year/years`、指标和计算版本。缺少范围时追问；明确全域时才查询全域，来源过滤始终独立执行。自有/移植默认分别展示；不以名称前缀推定新导入通量来源。

自有地块沿用现有归属；移植地块从已核验乡镇映射沿区域目录父链向上聚合。核验父类型、缺失父节点、环、重复和停用节点；每个目标区域内同一记录只计一次。无法映射记录披露数量和原因，不能随意归给相邻地区。地块结果按样点计数；行政统计为记录统计，单位面积通量不直接相加为区域总量。有有效面积及去重核算规则后才提供区域总量，否则明确不支持。

### 2. 年度、企业输入与历史兼容

通量输入/输出新增 `accounting_year`、来源及可追溯导入批次/依据；输出记录计算版本、输入修订和八分项覆盖。逻辑唯一键为来源、地块、样点、业务年度；输出另带计算版本以避免新版覆盖旧口径。年度未知单独保存，使用部分唯一索引或等效约束防止 NULL 产生重复；实施时根据目标 PostgreSQL 版本确定 DDL，并测试数据库真实约束。

新增 `enterprise_input`（g/ha/a）可空：空为未知，0 为明确零。新导入契约要求年度和来源；旧 CSV 通过显式 legacy 导入模式保留年度未知、企业未知和七项口径，不静默升级为八项。历史年份仅在有证据的独立补录流程中更新。输入修订后旧输出必须标注过期，不能继续表现为当前结果。

按年度分别查询并列对比，返回样点/地块数量、来源、版本与覆盖差异。覆盖不同的年度不直接宣称污染改善或恶化；年度未知不混入某年。当前预测表无业务年度依据，本次年度能力针对通量，Cd 预测图仍披露时期未知。

### 3. 单位核验与纯试算

建立参数契约：四输入（沉降、灌溉、农化、企业）、四输出（渗漏、径流、籽粒、秸秆），均为 g/ha/a；初始 Cd 储量为 g/ha，初始浓度为 mg/kg，二者不得互换。核验容重单位、土层厚度、时间跨度、常数 2000 的量纲及原迁移公式证据，形成独立核验记录和人工可复算样例，不能只以新旧函数输出相同证明正确。

完整八项时 `In = deposition + irrigation + agro + enterprise`，`Out = leaching + runoff + grain + straw`，`Net = In - Out`。末期浓度采用通过核验且带版本的单位换算公式，跨度为明确的一年；核验前不发布该输出。缺项可返回已知小计及缺项清单，但不得发布完整净收支或末期浓度。负容重、非有限数、无依据单位转换拒绝计算；不再将非正土壤质量转换为正常零浓度。

提取无数据库副作用的计算核心，业务核算和对话共用。纯试算不需要虚构样点编号，用户给定年度为情景标签，不证明输入为实测。可查询匹配地区/地块/年度已有参数及来源；行政均值不自动替代地块参数。默认值须列明数值、依据与适用性并逐次取得明确接受；企业输入不提供隐含零默认。

### 4. 对话操作与连续性

在现有 `cd_conversation_query` 扩展受验证的操作：通量统计、明细、参数、试算、年度对比、制图、导出。能力目录区分查询、试算、管理操作及就绪原因。批量导入和覆盖业务重算不注册为对话工具。

沿用服务器验证的分析对象和草稿 revision。草稿增加计算类别、年度、来源、各参数单位/依据/默认接受记录、公式版本。切换地区、年度或计算类别时清除或重新核验受影响值；迟到响应不覆盖新版。保存基于服务器已完成消息结果，扩展 `CdTrial.payload` 的类型和版本，沿用归属、事务、唯一键和重试；独立保存不会更新通量业务表。

结果结构保留状态、条件、口径、覆盖、单位状态、实际输入与附件引用。普通 HTTP 与 SSE 通过相同归一化层输出；普通后续语句“画成图”“导出刚才的数据”继承已验证条件，不扩大查询范围。

### 5. 受权附件与可视化

新增产物登记，关联用户、会话、消息/结果 revision、参数快照、文件种类、生成状态和实际文件。服务端决定路径与文件名。附件只返回不透明 ID、受权下载 URL、MIME、标题、大小及元信息，不能返回服务器绝对路径或 URL 中的访问令牌。

预览/下载每次同时校验登录、会话归属及产物关联；现有全局列表与下载也必须限制，防止由旧入口绕过。无 owner 的历史产物不默认对所有用户开放，须按已有管理权限处理。删除会话后立即撤销访问，清理文件通过幂等任务处理；失败生成不发布半成品附件，重试绑定同一请求修订防重复。

复用预测制图与通量制图引擎。默认不插值；仅预测图开放现有插值选项，显式请求才启用。通量图目前不支持插值，明确提示而非忽略参数。图表记录样点/像元数量、模板外剔除数、实际使用/总点数、截断状态、边界来源、图例与单位状态。超过点数上限的图只作为明确标识的局部展示；CSV 超过 10 万行拒绝且不截断。制图参数与资源范围验证，缺绘图依赖只影响制图能力，不拖垮统计入口。

预测图可下载已有 GeoTIFF，通量图本轮提供地图和直方图。像元直方图与原记录统计分别标注；图例不输出“安全/超标”定论。前端通过携带登录凭据的请求获取文件并预览，不能假设普通 Markdown 图片请求能附带 Bearer token。

### 6. 迁移与回滚

迁移先检查表结构、重复键、年度/来源依据、现有行数和回滚备份；新增字段及索引后验证守恒。旧结果保留 legacy 版本，未知字段不填零。新旧入口显式标识契约版本，避免旧客户端误写年度表。

回滚首先关闭新能力入口；已有新年度/企业数据不删除，数据库降级前必须导出并检查能否无损恢复旧唯一键，发生冲突即停止降级。使用迁移演练库验证升级幂等、失败事务和恢复，不直接在开发业务库试删表。

## Risks / Trade-offs

- 结构支持不等于有数据：缺年度证据、企业输入或上级映射时，能力返回具体缺项，不承诺全区域全年度可答。
- 本仓库无已找到的聊天前端：后端契约验收和真实预览验收分别记录，前端未接入不得归档为全部完成。
- 科学公式核验可能阻塞末期浓度上线；查询旧结果必须显示旧版本和单位状态，不能借接入对话宣称已核验。

## Validation Strategy

按 tasks.md 顺序验证：数据库迁移与索引、单位独立样例、范围/来源/年度对照、HTTP/SSE 多轮与保存、附件越权/失败/截断、前端预览及真实数据链路。替身 LLM 测试只验证协议；另需配置真实模型的端到端人工验收并记录环境。历史 227 项通过不能替代本次回归。
