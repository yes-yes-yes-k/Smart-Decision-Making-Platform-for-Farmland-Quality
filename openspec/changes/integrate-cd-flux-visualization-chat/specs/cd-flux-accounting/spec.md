## MODIFIED Requirements

### Requirement: 输入行导入

系统 SHALL 支持版本化通量输入导入。新版 MUST 包含地块、样点、来源、业务年度、初始 Cd 储量、七项既有通量及企业输入字段，容重 MAY 提供；企业输入允许未知但 MUST 与明确零区分。数值、单位及年度 MUST 校验，同一来源/地块/样点/年度覆盖更新并返回计数。旧 CSV MUST 仅在显式 legacy 模式接受，保留未知年度和企业未知。缺列或非法行 MUST 拒绝整批且不得部分写入。

#### Scenario: 导入完整输入行
- **WHEN** 导入同一来源、地块、样点、年度的有效新版输入
- **THEN** 系统 MUST 更新该年度输入并标记旧输出过期，不影响其他年度

#### Scenario: 历史兼容
- **WHEN** 显式导入无年度、无企业输入的旧格式
- **THEN** 系统 MUST 保留未知状态和 legacy 来源依据，不推断导入年份或企业零值

#### Scenario: 缺少必需列
- **WHEN** 输入缺必需列或含非法数值/年度
- **THEN** 系统 MUST 返回机器可读错误并保持整批未写入

### Requirement: 通量计算

系统 SHALL 通过同一无写库计算核心执行八分项核算：四项输入之和为 In，四项输出之和为 Out，Net 为 In−Out。初始储量、容重、土层和一年跨度 MUST 满足经核验的单位契约后才生成末期浓度；公式 MUST 版本化。缺项 MUST 保留未知并仅提供已覆盖小计；默认值 MUST 显式披露并经接受，企业未知 MUST NOT 自动按零处理。非正容重/土壤质量及非有限值 MUST 拒绝。业务重算按来源/地块/样点/年度/版本幂等保存；对话试算 MUST NOT 写业务输入输出表。历史七项结果 MUST 保留旧版本，不能作为完整八项结果。

#### Scenario: 正常计算
- **WHEN** 用户提供单位明确且有效的四项输入和四项输出
- **THEN** 系统 MUST 返回完整输入、输出与净通量并记录版本；末期浓度只在额外条件齐备且单位公式已核验时返回

#### Scenario: 企业输入未知
- **WHEN** 企业输入为空而其他七项齐全
- **THEN** 系统 MUST 显示缺少企业输入及已覆盖小计，不返回伪完整净通量或末期浓度

#### Scenario: 明确零值
- **WHEN** 用户明确给出企业输入为 0 g/ha/a
- **THEN** 系统 MUST 将其作为有来源的有效分项参与核算

#### Scenario: 容重缺失
- **WHEN** 完整浓度试算缺少容重
- **THEN** 系统 MUST 请求补参或明确接受有依据的默认值，接受前不返回末期浓度，接受后记录数值及来源

#### Scenario: 重复计算幂等
- **WHEN** 执行对话试算或重复同年度同版本业务重算
- **THEN** 对话试算 MUST 保持业务表不变，业务重算 MUST 保持唯一键幂等且不覆盖其他年度或旧版本

### Requirement: 通量统计与分布

系统 SHALL 对 in_cd/out_cd/net_cd/end_cd 按来源、年度、版本和实际覆盖分别统计，保留总体标准差、下标直取分位数和六位小数口径。记录均值 MUST NOT 称为面积总量。net_cd 使用互斥 `<−5 / −5至5 / >5` 分档；in/out 保留相对本批均值分档并标明不可跨批直接比较；end_cd 的 0.3/0.6 仅为历史展示阈值，MUST 保留单位状态及来源依据，MUST NOT 宣称普遍安全或超标结论。所有分档 MUST 互斥。

#### Scenario: 覆盖不同的年度
- **WHEN** 对比两个样点覆盖不同的年度
- **THEN** 系统 MUST 并列数量、覆盖和口径，不把均值差异直接解释为同一批地块变化

#### Scenario: 分档解释
- **WHEN** 展示净通量、相对均值或浓度分布
- **THEN** 系统 MUST 标注边界和展示含义，保证每条有效记录最多落入一个档位，不据此作超标判断

#### Scenario: 净通量分布互斥
- **WHEN** 统计 net_cd 分布
- **THEN** 每条有效记录 MUST 仅落入一个档位，三档占比之和 MUST 不超过 100%

#### Scenario: 当年浓度三档
- **WHEN** 展示 end_cd 的历史三档分布
- **THEN** 系统 MUST 保留 0.3/0.6 边界及其原迁移依据、单位状态，将其标识为展示分级而非通用超标判定

#### Scenario: 相对分级标注
- **WHEN** 统计 in_cd/out_cd 分布
- **THEN** 系统 MUST 标注 relative=true 与跨批不可比，不描述为绝对等级

### Requirement: 空间结果

系统 SHALL 提供按同一来源、年度、版本和地区筛选的点位、地图和直方图；坐标来源 MUST 标注地块质心。地图 MUST 保留净通量互斥分档、浓度历史阈值及输入/输出分位数展示模式，不将展示等级当作风险结论。产物 MUST 记录总点数、使用点数、模板外剔除、截断状态、单位与边界来源；像元统计 MUST 与原记录统计区别。

#### Scenario: 制图点数超限
- **WHEN** 请求范围超过制图取点上限
- **THEN** 系统 MUST 拒绝并提示缩小范围或明确将结果标识为截断展示，不得称为完整区域图

#### Scenario: 通量地图口径
- **WHEN** 生成净通量地图及直方图
- **THEN** 系统 MUST 使用同一筛选范围和栅格，标注质心、像元口径、单位和互斥边界

#### Scenario: 点位 GeoJSON
- **WHEN** 请求某年度范围内通量点位
- **THEN** 系统 MUST 返回含 value、单位、地块/样点的 FeatureCollection，并标注地块质心来源

#### Scenario: 通量地图
- **WHEN** 生成 net_cd 地图
- **THEN** 系统 MUST 使用负/平衡/正互斥分档，元信息包含 g/ha/a、年度、来源及覆盖

### Requirement: 明细与导出

系统 SHALL 提供分页明细和 CSV 导出，字段 MUST 包含所请求指标、来源、地块/样点、业务年度、版本及覆盖状态，过滤条件 MUST 与统计一致。CSV MUST 限制为最多 10 万行，超限 MUST 报错而不静默截断。

#### Scenario: 导出 CSV
- **WHEN** 用户导出某来源某年度结果
- **THEN** CSV MUST 仅包含该范围，未知年度不得混入；超过行数上限 MUST 返回可读错误

## ADDED Requirements

### Requirement: 年度迁移与历史保真

系统 SHALL 增加业务年度、企业输入及来源/计算版本的可追溯信息。旧记录 MUST 保留年度未知、企业未知和原结果，未知年度记录也 MUST 受唯一性约束。迁移 MUST 幂等并验证行数、键冲突和失败回滚；存在新年度数据时 MUST NOT 通过删除数据或合并冲突键强行降级。

#### Scenario: 迁移旧记录
- **WHEN** 对没有业务年度的旧库升级并重复执行迁移
- **THEN** 系统 MUST 不猜年份、不填企业零值、不产生重复记录且保留原结果

#### Scenario: 回滚存在冲突
- **WHEN** 新数据包含多个年度，无法无损恢复旧唯一键
- **THEN** 系统 MUST 停止破坏性降级并给出保留/导出数据的恢复说明

### Requirement: 全层级范围与独立来源过滤

系统 SHALL 支持省、市、县、乡镇、地块以及明确请求的全域范围。来源过滤 MUST 独立于地区过滤。上级聚合 MUST 采用可核验的地块归属与行政父链，检查重复、缺失、循环和停用节点；未映射记录 MUST 单列披露。年度未知 MUST 不混入指定年。范围/年度不支持与范围内无数据 MUST 返回不同状态。

#### Scenario: 全域仅查移植来源
- **WHEN** 明确全域查询且指定 ported 来源
- **THEN** 系统 MUST 过滤掉自有来源，不能因未指定地区而跳过来源校验

#### Scenario: 乡镇向上聚合
- **WHEN** 移植数据有合法乡镇归属及完整上级父链
- **THEN** 系统 MUST 支持县市省聚合并去重，显示实际覆盖乡镇和记录数量

#### Scenario: 归属缺失
- **WHEN** 地块或父链缺失、冲突或形成循环
- **THEN** 系统 MUST 披露未覆盖原因，不猜测归属或将其纳入目标区域
