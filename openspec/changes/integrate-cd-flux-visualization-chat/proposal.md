# Cd 通量、年度分析与制图对话集成

## Why

zsj_1107 已提供通量业务核算和 Cd 制图，但对话仍报告通量未接入。直接调用现有计算会覆盖业务结果；数据缺少业务年度和企业输入，移植来源仅支持乡镇归属，附件仅校验登录而未校验会话归属。因此需要先补齐数据契约，再接入查询、独立试算和图表下载。

## What Changes

- 扩展省、市、县、乡镇、地块查询；使用经核验的归属逐级汇总，披露实际覆盖和未映射记录。
- 为通量增加业务年度、年度唯一键与逐年对比；历史未知年度不推断。预测记录没有年度依据时仍明确返回不支持。
- 增加企业来源输入，与沉降、灌溉、农化输入共同核算；未知与零分开，历史七项结果保留旧口径。
- 接入通量统计/明细、参数查询、多轮补参及无写库试算；明确保存时写独立试算记录。
- 接入预测及通量地图、直方图、受权 CSV 下载；预测图保留可选 GeoTIFF；普通聊天与 SSE 返回相同附件契约。
- 修复来源过滤，核验公式/单位；添加附件归属与旧下载入口的防绕过校验。
- **BREAKING**：通量年度键、企业缺项语义和公式版本改变现有核算契约，必须版本化迁移，禁止无提示覆写旧结果。

## Capabilities

### New Capabilities
- `cd-chat-artifacts`：会话图表/导出附件的生成、访问控制与展示契约。

### Modified Capabilities
- `cd-flux-accounting`：年度数据、八分项、单位验证、统计与导出语义。
- `cd-conversation-analysis`：通量查询、年度对比、多轮试算、空间覆盖与保存。

## Impact

涉及 `cd_flux` 模型/服务/管理接口、Cd 空间归属服务、`cd_conversation` 工具、聊天上下文和独立试算保存、制图产物下载及相关测试。复用现有服务，不由语言模型计算数值。

本仓库提供附件接口及契约；真实聊天图片预览需前端消费方联调，单列验收。实施按 tasks.md 阶段顺序执行，前置阶段未验收不得宣布后续阶段完成。

## Non-Goals

- 不向自然语言工具开放 CSV 批量导入或覆盖业务表重算。
- 不开发企业排放扩散/沉降模型，不从企业排放总量直接推算土壤输入。
- 不自动补造历史年度、企业零值或缺失地区数据。
- 不实现未来多年浓度预测，不把图表分档当作超标/安全结论。
