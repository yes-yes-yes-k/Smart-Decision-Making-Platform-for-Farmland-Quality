## Context

当前酸化智能体已具备模型调用与结果处理逻辑。本变更增加聊天入口，让用户从 `@` 菜单显式选择酸化或降酸模型，随后确认基于当前地块预填的输入，再进入现有调用流程。

## Goals / Non-Goals

**Goals:**
- 以 `@` 打开两个模型选项。
- 选择后展示当前地块数据预填的输入框。
- 复用现有酸化智能体调用逻辑并保留模型各自参数要求。

**Non-Goals:**
- 修改模型算法、训练资产或既有计算接口契约。
- 自动推断或填造地块中不存在的数据。

## Decisions

- 在聊天输入框处理 `@` 触发的模型选择状态；用户选项分别映射酸化与降酸既有调用路径。替代方案是另建一套通用路由，但会重复现有智能体逻辑并造成行为分叉。
- 模型选择后读取当前地块上下文并预填输入表单；保留可编辑能力，缺失值保持空缺并遵循现有校验。替代方案是直接提交预填值，无法让用户核对和补充。
- 提交时复用当前酸化智能体的参数组装、调用及结果展示流程，并将选定模型作为明确意图传入，避免依赖模型猜测用户选择。

## Risks / Trade-offs

- 当前地块字段与模型字段映射可能不完整 → 预填仅使用已映射字段，缺失项由表单和现有校验处理。
- 降酸模型的具体输入与酸化模型不同 → 表单按选中模型展示对应字段，并沿用该模型现有调用逻辑。
- 用户在选择后切换地块可能造成数据过期 → 提交前确保表单对应当前地块上下文。
