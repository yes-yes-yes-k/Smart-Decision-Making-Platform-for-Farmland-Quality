# add-farmland-spatial-statistics Design

## Context

`parcel_info` 已保存地块几何和 `soil_indicators`，但缺少可用于县、镇、村选择的完整区域面目录。历史导入脚本还把所有地块的 `area_code` 固定成 `440233`，因此按编码聚合既无法支持地图视窗，也不能保证县域结果正确。

前端需要 8 项指标的表格、横向柱状图和饼图，并要求地图缩放、平移后统计随当前视窗变化。本设计把“统计范围”定义为空间几何，把 `area_code` 降为经过审计的地块属性，不把它作为统计范围的唯一依据。

## Goals / Non-Goals

**Goals:**

- 提供县、镇、村和地图视窗统一的统计入口。
- 固化指标边界、开闭区间、颜色和最高档不封顶规则。
- 使用真实相交面积计算总面积、分档面积和面积加权平均值。
- 支持地图点选地块及完整地块面积、最小必要指标展示。
- 纠正历史硬编码区域，并保留完整审计和回滚能力。
- 保留争议边界事实，不把争议面任意分配给普通村。

**Non-Goals:**

- 不提供卫星影像瓦片或前端地图组件。
- 不自动裁决行政边界争议。
- 不对低置信跨界地块做不可逆修改。
- 不修改耕地质量评价等专题模型的计算逻辑。

## Decisions

### 1. 统计范围以几何为准

行政区域请求从 `spatial_region_catalog.geom` 读取范围；视窗请求用 EPSG:4326 的 bbox 构造范围。查询先使用地块 GiST 包围盒索引和 `ST_Intersects` 过滤，再对命中地块执行 `ST_Intersection`。

该方案保证地图视窗和跨界统计正确，也使剩余 162 个低置信 `area_code` 不会污染统计结果。

### 2. 面积按范围裁剪，平均值按面积加权

地块只要与范围产生正面积相交就计入地块数；总面积和等级面积只累计裁剪后的部分。指标平均值使用裁剪面积加权，而不是简单地块平均。

接口同时返回有效指标地块数/面积和 `unclassified` 地块数/面积。缺失、无法解析或不属于有效正值范围的数据不得静默进入最低档。

### 3. 分级配置是后端唯一事实来源

`indicator_definitions.py` 统一保存 8 项指标的字段映射、单位、精度、区间和颜色。`GET /metrics` 将该配置直接提供给前端，避免接口、图例和图表分别维护阈值。

有机质、有效磷、速效钾和容重的最高档均改为无上限。例如有效磷 `(35,+∞)` 使用同一“高”档颜色，40 以上不产生新档位。

### 4. 柱状图和饼图共用等级分布

每个指标返回有序 `distribution`。每档包含 `parcelCount`、`areaMu`、`countPercent`、`areaPercent`、`rangeLabel` 和 `color`。柱状图使用 `parcelCount`，饼图可按产品选择使用数量或面积，但不得另行计算分档。

### 5. 地块详情面积使用完整几何

地块详情和经纬度点选均返回 `areaMu`。该值使用完整地块 `geom::geography` 的测地面积换算为亩并保留 4 位小数，不受当前行政区域或地图视窗裁剪；几何缺失时返回 `null`。这与聚合接口的面积单位一致，但统计范围不同。

### 6. 区域目录支持多级面和争议区

区域目录增加 EPSG:4326 MultiPolygon 几何及 GiST 索引；对象类型增加 `township` 和 `village`。父级链为省—市—县—镇—村。

乐昌村界中的 73 个“村与村争议地”以 `zone` 保存，`selectable=false`。普通统计选择器默认不返回争议区，但管理核查可显式请求。

### 7. 地块区域纠正采用高置信阈值

县级归属以地块在等面积坐标系下与各县的面积重合比例判定。主导县覆盖比例达到 95% 时，错误编码才允许自动更新；否则记录为 `review_required` 并保持原值。

每次正式执行保存原编码、推断编码、点位置编码、重合比例、相交县列表、边界文件哈希和批次 ID。回滚仅恢复当前编码仍等于该批次推断值的记录，避免覆盖后续人工修改。

### 8. 边界替换必须先差异审计

导入器默认 dry-run，检查 CRS、空几何、无效几何、编码唯一性以及县—镇—村覆盖拓扑。显式 `--apply` 后才以事务更新目录并禁用被替换来源。

当前土壤所广东 L2/L3 与原广东数据逐字节一致，L4 中乐昌 294 个要素也与原乐昌独立村界逐属性、逐几何一致。因此来源登记已替换，但无需再次修改地块归属。

### 9. API 沿用 JWT 和统一错误包络

新增端点：

- `GET /metrics`
- `GET /regions`
- `POST /aggregate`
- `GET /parcels/{parcel_id}`
- `POST /parcels/pick`

输入错误返回 400，区域或地块不存在返回 404，区域缺几何返回 409，空间服务不可用返回 503；未预期错误返回固定 500 包络，不向客户端泄露内部异常。

## Migration and Rollback

1. 为既有 `spatial_region_catalog` 增加可空几何列和 GiST 索引。
2. 导入乐昌县、镇、村和争议区，省市仅作为父级目录占位。
3. 对地块县级归属先 dry-run，确认分布和阈值后再写入审计及高置信更新。
4. 若需要撤销地块纠正，按审计批次运行 `--rollback-run <run-id>`。
5. 若替换边界，先比较几何与属性差异，再重新执行地块归属 dry-run；仅有新增高置信变化时才创建新写入批次。

## Risks / Trade-offs

- [边界版本较旧] → 保存来源与沿袭信息；获得最新权威边界后按同一流程替换。
- [跨界地块数量口径] → 地块在每个有正面积相交的范围中计数，面积只计相交部分；文档和前端保持同一解释。
- [实时视窗统计压力] → 使用 GiST 索引，前端在 `moveend` 后做 300–500 ms 防抖并取消过期请求。
- [测试数据被误当正式成果] → 接口返回真实数据库值，但文档明确当前地块指标来源仍是测试数据。

## Open Questions

- 162 个低置信地块需在获得更精细边界或人工判读结果后处理。
- 正式上线前需确认最新权威行政区划版本和正式地块指标数据源。
