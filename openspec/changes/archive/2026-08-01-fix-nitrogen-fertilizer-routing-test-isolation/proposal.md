# 修复氮肥施用量路由与集成测试隔离

## Why

“我的田施氮肥施多少？”未命中模型 6 的关键词，错误路由为 `question_type=0` 并进入 RAG。该问题属于耕地肥力 SOC/Dose 预测能力的施肥量咨询，应由 `model-6` 处理。

聊天 API 集成测试同时依赖本机配置的 LLM、RAG/向量检索和默认数据库，导致路由测试可能因无关外部运行时而等待或不稳定。

## What Changes

- 将氮肥施用量问题识别为 type 4，并路由到 `model-6`。
- 将聊天 API 集成测试隔离为本地、确定性的路由与降级验证。

## 非目标

- 不改变模型 6 的输入、预测算法、输出字段或模型文件。
- 不改变生产环境的 LLM、RAG 和数据库配置。
