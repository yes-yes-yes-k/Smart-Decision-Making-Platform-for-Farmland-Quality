# Cd 对话接入设计

## Context

用户已确认需求与验收方向，详见 `docs/cd-conversation-design.md`。现有专题工具注册位于 `framework/function_calling/specialized_tools.py`，聊天节点通过工具清单执行服务。土壤区域统计在 `framework/api/services/farmland_statistics.py` 中按相交面积加权，Cd 预测统计提供记录分布。两类结果共享自然语言入口时需要保留各自含义。

## Goals

通过现有聊天入口完成统计、参数查询与参数预测，支持跨消息补参和按需保存。能力可用性由后端服务、数据覆盖及契约共同决定，输出可追溯到来源和计算版本。

## Decisions

### 工具与对象解析

沿用现有工具注册、执行链和规范分析对象。按查询统计、查询参数、执行预测、保存试算划分操作，能力查询用于确定实际支持范围。服务端验证地区类型和标识，地名歧义返回候选并追问。纯参数计算使用已验证的 scenario 输入，可在参数齐全时独立执行；地区参数查询和区域统计要求相应合法对象。

### 能力与结果契约

能力描述包含污染物、指标、数据类别、操作、地区层级、时间支持、输入契约、单位状态及就绪原因。八类通量逐项登记，首批开放经过核验的已有服务。

结果保留服务字段，通过对话适配携带地区、统计时期、测量时期、来源、统计方法、数量对象、有效面积、覆盖、单位及核验状态。状态区分成功、缺参数、无数据、能力不可用、单位未核验和服务异常。展示简短结论、表格、口径和来源，数值由服务返回。

### 统计与时间

土壤使用面积加权均值、有效地块数及面积，预测结果使用算术均值和中位数等分布统计。自有与移植来源默认分别查询，避免服务默认 `source=all` 混合展示。保留原服务分位数与总体标准差算法。

土壤年度快照返回统计年度、测量年份、插补信息。预测结果服务缺少年度过滤能力时，对指定年份请求返回限制并询问是否查看时期未知的数据。查询时间仅用于说明执行查询的时间。

### 多轮参数状态

参数草稿按已认证用户及会话隔离，包含版本、规范对象、时期、指标、模型版本、参数值与单位、来源及适用范围、缺项和最近结果标识。复用现有会话存储可行部分，实施前核对生命周期。

用户修改指定项时创建新的草稿版本，重新校验受影响项。切换地区或时期时失效相应自动获取参数并重新查询。用户提供参数依适用范围保留或追问，经验默认值记录接受状态。并发消息和迟到工具响应必须绑定草稿版本，过期结果不能覆盖当前参数。

### 计算与保存

计算调用 `heavy_metal_cd.predict` 等纯服务，输入经过完整性、数值范围和单位校验。预测自身的单位核验状态随结果返回；依赖未核验单位的换算、通量计算或超标判断需等待核验。

按照 ADR 0005，保存采用独立试算记录，包含所有者、会话、结果标识、完整参数及来源、地区与时期、计算版本、输出和创建时间。同一所有者的同一试算结果使用唯一约束及事务保证重复请求返回原记录。改参重算生成新结果标识。保存失败保持结果可重试，读取与保存检查会话及记录归属。

## Migration Plan

实施时新增试算记录迁移，并明确会话草稿的持久化方式。先部署兼容新增结构，再启用对话工具。回滚应用时可保留试算记录供恢复，任何删除记录的数据库回滚都须先备份并说明影响。既有批量预测写入按地块覆盖结果，应通过独立试算存储落实已确认的保存语义。

## Risks and Verification

原网站当前不可访问，历史本地源码路径不存在，通量公式与数据可用性需要在对应迁移阶段重新核验。各地理层级的实际覆盖尚未连库验证。已有预测单位为 unverified，交付验收需包含该真实限制。

覆盖工具级与正常聊天入口的集成场景，包括普通和 SSE 输出、会话隔离、并发改参、保存重试及既有工具回归。真实数据库验证记录环境、查询范围与结果，无法执行时保留明确的未验收任务。
