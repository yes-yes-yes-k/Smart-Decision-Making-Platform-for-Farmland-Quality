## Context

酸化 RF 接口定义了部分指标单位可能未经核验，但用户表单另有默认单位。面向用户的解释把输入未显式携带单位误认为单位缺失，把下降量当成 0–1 风险分数；降酸解释还可能没有使用请求中明确传入的目标 pH。

## Goals / Non-Goals

**Goals:** 解读使用已知的表单默认单位；准确呈现请求中的目标 pH；准确解释预测字段的含义与单位；不凭空补充分数范围或风险等级。

**Non-Goals:** 修改模型、预测数值、风险阈值或指标单位配置。

## Decisions

以输入字段定义和界面默认单位作为展示依据。若字段确实没有经过核验的单位，继续遵守现有契约，不编造具体单位。解释层按模型输出字段的正式语义描述下降量；不将其归一化成概率/风险分数，也不附加未经定义的严重程度标签。

替代方案：在解释文本中临时硬编码单位与范围。此方案容易与表单或模型契约不一致，因此不采用。

## Risks / Trade-offs

若默认单位定义在界面和接口间不一致，解释仍可能误报 → 实施时核对表单字段配置，并仅对有明确默认单位的字段展示单位。

## Migration Plan

无需数据迁移或模型部署变更；更新解释逻辑并依据场景验证。回滚时恢复原解释模板。
