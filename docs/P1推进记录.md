# P1 后端推进记录

更新日期：2026-09-18
当前状态：**首版已实现，可进入前端联调**

## 已完成

### 行政边界 GeoJSON

- 新增 `GET /api/v1/farmland-statistics/boundaries`。
- 支持行政层级、父级、WGS84 bbox 和 zoom 过滤。
- 返回区域代码、名称、父级、是否可选、`minZoom` / `maxZoom` 和 GeoJSON 几何。
- 省、市、县、镇、村/争议区最小缩放级别分别为 3、5、7、9、12。
- 指定 zoom 时按像素尺度简化几何；单次上限 5000 个要素并返回 `truncated` 状态。

### 多行政区联合统计

- 聚合接口新增 `administrative_regions` 范围类型。
- 首期只允许一个 `region_type` 下的同级区域 ID 数组，一次最多 100 个。
- 使用 `ST_Collect` + `ST_UnaryUnion` 合并边界，避免重叠面积重复。
- 高顶点合并边界会先用 `ST_Subdivide` 无损分片，再通过 GiST 空间索引裁剪地块并按地块汇总。
- 响应按请求顺序返回参与统计的区域列表。

### 自定义多边形统计

- 聚合接口新增 `polygon` 范围类型，支持 GeoJSON Polygon / MultiPolygon。
- 校验坐标范围、环闭合、PostGIS 几何合法性、顶点数和测地面积。
- 限制为最多 5000 个顶点、最大 200000 平方公里；超限返回 HTTP 413 和明确业务错误码。
- 服务端统一多边形环方向，并继续使用地块 GiST 索引。

### 统一指标配置

- 指标定义仍是名称、单位、阈值和颜色的唯一来源。
- 指标配置、聚合统计和地块详情统一返回 `classificationVersion=2026-09-18.1`。
- 聚合指标和地块指标均返回 `metricKey`；地块详情的等级、区间和颜色直接来自同一配置。

## 真实库联调结果

以下为本机开发库单次功能联调结果，不代替并发压测：

| 场景 | 结果 | 单次耗时 |
|---|---:|---:|
| 乐昌市下镇级边界，zoom=10 | 17 个 GeoJSON 要素 | 0.294 s |
| 乐昌市 + 南雄市联合统计 | 1876 个地块 | 1.978 s |
| 0.1789 km² 自定义多边形 | 1 个地块 | 0.011 s |

联合统计优化前约 33.817 s；边界无损分片后约 1.978 s，统计仍基于合并后的真实行政边界。

## 自动化验证

- 边界缩放抑制和 GeoJSON 属性。
- 多区域输入顺序与 `ST_UnaryUnion` 合并。
- Polygon 类型、坐标、闭环、顶点及 PostGIS 合法性校验。
- 指标配置版本在元数据、聚合和地块详情中一致。
- 同一指标值在聚合分布与地块详情中的等级、区间和颜色一致。
