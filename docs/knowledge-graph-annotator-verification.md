# AI 标注者及协议验证结果

2026-10-27。验证范围为独立于真实评测集的合成短控制，不修改v3/v4参考或抽取后端，不提交剩余90条。结论：简单规则多数能够执行，完整标注协议仍不可靠；先校准提示和字段协议，再验证真实试标，不宜将之前的所有失败都归因于模型不懂领域。

## 一、基础规则控制

17个合成短控制，各无修复重复两次，总计34次真实调用。模型、温度和现有关闭思考的设置固定；两轮是稳定性检查，不是独立标注者。所有预期答案提前落盘，模型不接收答案表；连通性控制刻意要求返回READY，不作为语义能力证据。

| 类别 | 正确/请求 |
|---|---:|
| 实体类型/所属介质 | 13/14 |
| 肯定、否定、假设和题名限制 | 8/8 |
| 可评空集与乱码 | 4/4 |
| 规范名已知/未知 | 4/4 |
| 原文换行复制 | 2/2 |
| 连通性格式控制 | 2/2 |

合计33/34。唯一错误：第一轮把实验室对试剂“水浴加热”当成measure，第二轮答out_of_scope。预先规定全部两轮正确才通过，本轮资格仍未通过，不按结果事后放宽成95%。这些结果不等于真实文献抽取准确率。

原始响应、答案表、配置与规则SHA：`artifacts/knowledge_platform/gold-v4/annotator-qualification-v1/`。

## 二、配对输出协议检查

6个合成文本，分别做单项判断和完整v4表单，各重复两次，共24次调用。模型、系统规则和可见源文本相同，输出协议及附带说明长度不同；两种方式均使用JSON object，不将格式机制变化混入比较。

| 指标 | 单项判断 | 完整表单 |
|---|---:|---:|
| 尝试数 | 12 | 12 |
| 能从原始输出观察目标判断 | 12 | 10 |
| 目标判断正确 | 11 | 8 |
| 完整输出有效且目标正确 | 11 | 2 |

完整表单10次未形成完整可用结果：A质量却关闭可评任务6、标注字段错误1、模态错误2、超时1。不能将这些都说成目标语义判断错误。`common-target-audit.json` 保留了目标判对但其他字段失败的情况。

**设计局限**：探索性比较中，公共提示虽然去掉了“只有answer字段”，仍保留“完成一个判断”的措辞，可能影响完整表单。该比较不是纯粹的提示长度实验，也不足以独立证明表单复杂度导致错误。此缺陷明确登记，旧结果不删除、不覆盖、不作为放开扩量的依据。

证据：`annotator-protocol-load-v1/` 的原始响应、报告、共同目标审计及 `protocol-limitations.json`。

## 三、中性提示敏感性检查

针对上项措辞问题，以没有“单个判断/只输出answer”限制的公共提示，在“未知缩写”和“可读空集”两个已使用场景上做8次核查。单项4/4正确，完整表单4/4有效且目标正确。

这说明这两个场景在中性协议下能够完成，提示一致性值得优先修订；由于题目已使用、只有两类场景、两次重复及其他用户措辞也有变化，不能宣称已经建立纯因果解释，更不能推断10条真实文献或剩余90条已可稳定标注。原资格门槛不变。

证据：`annotator-neutral-prompt-v1/`，其中config保存实际中性系统提示和SHA。

## 当前决策与下一轮边界

1. 不新增抽取后端变体、不覆盖历史试标、不重试错误题直到答对。真实10条r3的失败门槛继续有效，剩余90条不运行。
2. 标注流程下一修订应统一系统/用户提示的任务数量和输出要求，逐项检查冲突；把原文mention、质量、规范化、关系拆开，不让可选规范名和质量布尔值一次生成的错误丢弃全部有效实体。
3. unknown规范名应由明确结构分支约束为null；A质量与任务可评布尔值须结构一致。保留原始提案和错误，不通过把未知强行改成known来过校验。
4. 任何局部正确片段只能进入待审队列，不能因流程技术修正就自动升级为金标；共同漏掉SOC等语义问题仍需原文独立复核。
5. 下一修订使用预先冻结的新短控制，再重做原10条真实试标；技术、语义和一致性都通过后才执行剩余90条。若仍失败，再评估其他标注者，不继续堆提示词。

本轮6项控制判分测试通过；原文、扩量门槛及r3的36项既有测试未修改。总调用66次（34+24+8），已报告token共35,341（8,427+20,441+6,473），实际费用未知，超时可能有未报告用量。全部验证进程已结束，专家认证与生产批准均为false。
