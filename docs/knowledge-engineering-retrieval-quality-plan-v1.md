## 目标与当前差距

优先让现有文献能够被可靠检索，并提供可持续运行的本机后端。首轮判断相关论文是否被找到、支持段落是否被找到及是否可回看原文；自动回答和跨论文对照分别检查。10k/100k验证延后，长期容量目标保留。

现有M2证明了当前112168块在隔离环境中的性能和恢复，没有证明相关性或证据支持质量。M1十篇共1306块，实际模型只查看80块；29条记录中2条通过定位、27条拒收，6篇空输出。原文定位通过不等于语义支持，空输出不等于全文无相关结果。详见[M1结果](knowledge-engineering-m1-results.md)和[M2结果](knowledge-engineering-m2-results.md)。

GraphRAG已有真实模型抽出实体/关系候选的隔离证明，但M1的两条研究记录属于另一读模型，不能替代KG候选、发布和图检索的贯通证明。新搜索只用词法，聊天读文件图，图API另走JSON/AGE，Claim图写入仍有缺口。后续闭环核实须分别追踪来源入库、候选持久化、实际图关联检索与独立审核发布；不能只修研究记录就声称整个图谱系统已贯通。

## 领域规则

- 研究问题可有多个研究子问题。命中文献不代表已找到支持段落，支持某个指标不代表整个问题已回答。
- 主题相关但尚无直接支持的文献可保留为背景相关。直接支持、条件明确性及知识发布身份分别表达，条件未知不当作条件吻合。
- 保留否定、不显著结果、适用条件、相反结果及不确定性。未检索到证据不解释为没有影响，也不据此断言全文没有证据。
- 每处支持必须可定位回当前有效的原文。来源撤回、权限收紧或版本变化后，旧原文和派生结果须失效。
- AI核实标明其身份与未决项；语义支持判断不能靠格式校验、宽松字符串匹配或多数票替代。

这些规则沿用[ADR-0001](adr/0001-separate-candidate-recall-from-published-claims.md)、[ADR-0002](adr/0002-source-retrieval-before-graph-dependent-comparison.md)及[ADR-0003](adr/0003-separate-evidence-support-conditions-and-publication.md)，不预先绑定检索供应商或数据库。

## 首批质量门槛

| 检查项 | 已确认门槛 | 失败或未知的处理 |
| --- | --- | --- |
| 文献召回 | 已核实相关的目标文献进入前10条文献结果 | 逐项记漏召回；重复分块不占多个文献名额 |
| 证据召回 | 对原文确实可回答的每个子问题，前5个证据候选至少一处真正支持它 | 背景片段不计支持；只答一个子问题不能算整个问题完成 |
| 来源定位 | 返回证据能够准确定位回原文 | 错源、错位置和无法回看的项不通过 |
| 语义与条件 | 保留条件、否定、不显著和相反结果 | 条件不符、未知及证据不足明确表达 |
| 报告方式 | 五类问题及检查变体逐项记录 | 不用平均分掩盖失败，不删除难项后声称通过 |

核验清单须在本轮对照运行前固定问题、来源范围、可回答子问题和判定依据。证据尚未核实的项记录未决，不编写支持标签；排名使用实际返回顺序，不事后挑选命中窗口。有限用例通过只表示首批可用性通过。

抽取另逐篇报告任务相关证据、有效待审研究记录、拒收原因和剩余缺口；记录数量、处理块数和格式通过率都不能独立表示覆盖完成。

### 上传到关联检索的闭环完成条件

原十篇验证不能只导入既有研究记录再查询。需逐项留下“来源文件与版本 → 文献审核/入库任务 → 分块与向量 → outbox/抽取任务 → 持久实体和关系候选 → 研究记录/断言与证据绑定 → 实际接口召回”的可追踪记录。使用隔离副本验证新文件或重放入库，清楚标注既有产物复用和本轮真实执行的步骤。

- 入库、抽取、候选和检索引用关联到同一有效来源版本；来源变化、权限收紧和撤回后，旧结果不可继续返回。
- 实体、关系及研究记录能持久保存，并由重新启动后的实际查询读取；不能以审计日志或内存构图代替写入/读取证明。
- 明确文献审核与候选发布两道门。候选辅助召回保留待审身份，新增已确认断言仍为0；已发布知识的审核门禁不绕过。
- 接口可追踪是否使用图、所用版本、图引入的来源与证据；图失败或无贡献须可识别，向量回退不能被写成图谱成功。
- 保留失败、取消、重启与队列计数，并检查Claim及条件化记录是否真正可查；只完成二元边或独立研究记录不算整个闭环完成。

### 图关联价值的验证口径

在相同来源快照、真实查询、候选与证据预算、模型/重排配置下比较：强词法/向量混合基线、具备同样领域过滤的基线、再增加图关联的路径。分开记录条件过滤收益和图路径收益，比较每个子问题的证据支持、换入/换出片段、成本及失败。既有26题缓存只用于机制诊断，原五类问题用于本轮领域任务，均不扩展成大规模评测项目。结果可以是图有增益、无增益、退化或证据不足，不预设新增平台必能改善。

- 保留历史银标、M1/M2冻结文件和原预算账本。重解析或重分块需要新版本、可重建映射及明确切换步骤，不原地改写旧快照。
