# GraphRAG 开发集错误分解与漏抽取实验（2026-10-27）

本轮已完成用户要求的开发集错误分解、实验版本实现和真实配对对照。v8-recall 保留为实验选项，不替换默认 v6。

## 交付

- 全开发集 699 分块的历史错误分解：`artifacts/knowledge_platform/gold-rebuild-v3/development-recall-v8/baseline-decomposition.json`，673 可评分、26 排除；逐条记录见同目录 `baseline-errors.jsonl`。
- 冻结 180 个开发集诊断样本（关系、仅实体、无事实各 60 个），两版各运行 180 次真实抽取。未使用验证集或测试集。
- 新增可选阶段诊断：每次原始 JSON、校验拒绝原因、通过校验的记录串和 GraphRAG 最终产物。默认生产调用不开启诊断、不启用 v8。
- `comparison.md` / `comparison.json` 保存评分、失败、token、转换检查和共同成功样本对照。

## 结果

| 指标 | v6 同期重跑 | v8-recall |
|---|---:|---:|
| 实体精度 | 77.86% | 58.59% |
| 实体召回率 | 17.75% | 28.34% |
| 实体 F1 | 28.91% | 38.20% |
| 关系精度 | 35.38% | 21.62% |
| 关系召回率 | 13.86% | 9.64% |
| 关系 F1 | 19.91% | 13.33% |
| 负样本正确数 | 60/60 | 57/60 |
| 失败 | 1 | 6 |
| 已报告 token | 131,027 | 175,659 |

v6 失败为 1 次方向错误；v8 为 4 次连接失败、1 次超时、1 次方向错误。负样本未正确完成的 3 个样本中有 2 个请求失败和 1 个非空预测。总计 306,686 个已报告 token；实际费用未知，失败请求可能存在未报告用量。

两版共同成功的 173 个分块上，v8 实体召回改善仍存在，关系精度和召回下降仍存在。不能将关系退化完全解释为网络失败。

## 定位与下一步

历史开发集 353 个正样本空输出；211 条漏抽关系中 206 条缺少端点。同期对照中，正样本空输出由 91 降至 63。所有成功真实产物的规范化实体、关系在转换前后均未丢失，说明本轮应优先改进模型抽取及语义约束。

仅加强单轮枚举提示不足以改善关系质量。下一轮待办为独立的实体枚举与关系判定两阶段流程，保留严格方向和原文证据约束，重点审查 addresses 误报，继续只使用开发集。当前参考集仍为 AI 审核，名称规范化、文档上下文及参考遗漏可能影响严格匹配；不要把全部漏匹配解释为模型漏抽。

验证：23 项相关测试通过；v6 的 179 份、v8 的 174 份成功真实产物全部通过来源与适配校验，零错误。此处是产物校验，不代表多次无缓存抽取一致性通过。证据仍采用全分块引用，精准短句证据尚未解决，生产发布保持关闭。
