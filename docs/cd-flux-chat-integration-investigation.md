# Cd 通量与制图对话集成调研

日期：2026-11-09。基线：本地 master `5dbb9da`，包含 Cd 对话 `48cefa1` 和 zsj_1107 `0f9d202`。本记录来自代码检查，不代表数据库已有覆盖或运行验收通过。

## 已迁移能力

| 能力 | 实现 | 对话接入方式 |
| --- | --- | --- |
| 作物/有效态 Cd 地图、直方图、可选 GeoTIFF | `heavy_metal_cd_visualization.generate` | 复用既有预测结果；添加会话附件与受权下载，不重新预测 |
| 三项输入、四项输出及净通量、末期浓度 | `cd_flux.calculate` | 提取无写库计算核心；对话不调用覆盖业务表的入口 |
| 通量区域统计、分布与分页明细 | `cd_flux.statistics/list_results` | 扩展 `cd_conversation_query`；结果披露来源、时期、记录数和覆盖 |
| 通量点位、地图和直方图 | `cd_flux.points_geojson/visualize` | 返回附件；明确质心坐标、有效点与像元统计区别 |
| CSV 导出 | `cd_flux.export_csv` | 生成受权附件；保留 10 万行超限报错 |
| CSV 导入及业务覆盖重算 | `cd_flux.import_csv/calculate` | 保留管理接口，不进入自然语言工具白名单 |

## 接入前缺口

1. `framework/agents/cd_conversation.py:65` 仍将通量全部返回不可用，没有制图/导出操作。
2. `cd_flux.py:124` 无地区条件直接返回，来源过滤失效；移植来源地区映射仅有乡镇。
3. `framework/models/cd_flux.py` 无业务年度，唯一键只有地块和样点；计算/导入时间不等于观测年度。企业输入尚无字段。
4. `cd_flux.py:239` 计算直接覆盖并提交业务输出，且自动采用缺省值；不能作为对话纯试算。
5. 初始 Cd 标注为 g/ha，七分项为 g/ha/a；末期公式及常数 2000 必须核验量纲和土层假设。不能把 mg/kg 初始浓度直接填入初始储量字段。
6. 可视化产物没有用户或会话归属。JWT 登录和文件白名单不能替代对象归属校验；全局列表/下载入口也要避免绕过新增权限。
7. 通量图读取上限 20000 点；需返回实际使用数、总数及截断状态，不能伪称完整区域制图。
8. 通量图尚不支持插值；预测图支持。地图分级、像元直方图与记录统计不可混用，图例不能直接作超标结论。
9. 本仓库未找到聊天前端工程。图片预览需定义附件契约并与消费方联调，后端测试不能替代真实界面验收。
10. 本次未重新验证绘图依赖、通量表迁移和实际数据覆盖；均须列入实施阶段检查。

## 已确认的产品决策

- 纳入统计/明细、参数查询、多轮试算、地图/直方图和 CSV 下载。
- 试算不修改区域业务结果；明确保存才保存独立试算；默认值须明确接受。
- 扩展地区、业务年度与企业输入能力，而非只接入现有七项核算。
- 聊天展示预览与下载附件，校验归属；默认关闭插值。
- 单位与公式核验是试算上线前置条件；分档不直接作安全或超标判断。

## 后续已确认的设计分支

- 地区覆盖省/市/县/乡镇/地块，使用可核验归属，未映射记录保持可见；已有数据覆盖不因支持上级汇总而扩大。
- 通量新增业务年度和年度唯一键，支持逐年查询对比；旧记录保留年度未知。试算年度由用户明确提供。
- 企业输入接收已换算的地块单位面积年通量；排除排放扩散/沉降模型。企业输入缺失保持未知，仅明确零值按零核算。

OpenSpec 按数据与单位核验、数据能力扩展、对话查询与试算、附件、验收的顺序组织。真实前端预览需外部消费方联调，不能以服务端通过代替。
