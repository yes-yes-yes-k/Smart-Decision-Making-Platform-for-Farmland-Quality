# M1最小实现与迁移设计

状态：M1隔离功能闭环已实现并验证；首期范围为已登记十篇真实文献，不声称抽取质量、千篇或十万篇服务验收。结果与覆盖缺口见`knowledge-engineering-m1-results.md`。

复用`SourceChunk`、`EvidenceReference`和稳定摘要。研究字段保存原文选择，字符跨度由程序从唯一摘录重建；不让模型自由生成规范名称或补缺失条件。保留同文献不同记录及原文条件，产物全部待审。

新增独立的研究记录/对照存储契约和产品蓝图。产品路由可挂载现有应用；试点使用相同蓝图的轻量应用与隔离持久数据目录，不初始化原应用或改变当前生产关系库。源文献及状态由注入的来源接口读取，每次查询、任务执行及结果复用重验。只读SQLite导出仅用于试点取数，不进入产品对Chroma的依赖接口。

迁移必须显式执行，预览/应用/回滚分离；构造服务不创建表。试点持久库只证明M1功能和恢复，不作为AGE或规模容量证明。后续挂载生产前仍须按实测设计目标持久层。

检索与对照为不同请求。对照持久排队并由有限worker消费；租约、取消和提交条件防止已取消任务被晚到结果复活。复用签名覆盖请求、来源内容/权限/状态、研究记录版本和生成配置。来源变化时旧结果失效；未知条件可以标注展示，但不视作请求条件已吻合。

模型只承担已核验来源中的有界研究记录选择，原文表格输出确定性组装，不额外生成无据归纳。十篇原件/重分块核验失败者仍保留登记并报告缺口，不替换为容易的文献。模型来源选择、批次和费用需独立预检并获预算归属授权，不使用外部评测余额。

必要验证：隐式迁移禁止、跨度与跨源伪造、未知条件、同文不同试验、权限变化、内容撤回、拒绝候选、取消/超时/租约恢复、缓存失效、重复请求、来源部分失败、图不可用降级，及真实十篇HTTP产品路径。测试使用独立unittest入口，避开根pytest配置自动初始化完整应用的副作用。
