# 标注片段协议试验结果

日期：2026-10-29。结论为 `fail / inconclusive`，批量标注保持停止。两版协议都只做小样本诊断，不能作为语义正确性或专家准确率估计。

## 发现的两类问题

第一版同时让模型返回字面引用及字符位置。20份初标里，12份因引用与位置不相等而被拒，6份通过结构检查，2份响应截断。原始响应保留在 `execution/quoted-selection-pilot-v1/`。对原响应做离线核算，49个初标片段中43个引用可唯一逐字定位、2个重复、4个无法在原文找到；这个结果说明程序可以从准确引用计算位置，不能说明这些引用在语义上正确。该版本的裁决并暴露候选展示适配错误，因此不能重分类旧响应为成功。

第二版改为模型返回逐字引用、程序定位位置，最多7道合成控制题及4条已知问题来源。原本计划22份初标和11份来源复核；全部原始输出已保存。复核器发现对嵌套关系证据的本地解析问题，初标错误不能按当时错误检查器计为失败或成功，故从原响应离线重放出新的候选复核包。此回放不覆盖原记录。

修正读取后完成11份AI来源复核，实际消耗包含一次限流重试。7道合成控制由AI拟定参考键，不是专家认证：明确提及施用石灰改善酸性土壤、提高pH的文本被判为实体和关系均无依据；实验室句中的有效磷遗漏；否定句中的实体遗漏；标准身份控制把编号/标题判断错；列表控制漏掉全部指标。英文正例因限流没有可用裁决。重复引文控制以及三条已知失败来源有不完整或无效裁决。至少有3条真实问题来源未得到候选修订。该结果说明逐字引用与程序定位修复了“模型手算位置”的一部分风险，但模型类型判断、候选覆盖和来源裁决仍不可靠。

## 预算和冻结状态

最终400条原队列没有续跑；上一批仍停在已保存的680/800份初标、322/400份裁决。新试验保存于独立目录，不改变样本成员、原响应、原校准银标或固定掩码。模型和来源裁决来自同一硅基流动 V4.1 Flash 系统，错误相关性未消除。

截至本报告，共2917次尝试、16908307 token已用或保守预留，inflight=0。全项目硬上限2000万token，剩余3091693；请求总上限5000次，并发2。稳定性阶段记录2404186 token，阶段额度当前250万。原授权与未知用量均保留。

原文12条抽查和两版协议试验均未通过质量门禁。因此100条冻结校准银标暂只供开发诊断，最终400条不得发布；候选后端及GraphRAG问答验收都未运行。

## 恢复前的工作

1. 修订实体和关系规则，直接说明 `soil pH`、酸性土壤、实验室方法、标准编号与全称、否定关系、重复实体及未检出候选应如何处理；控制题参考键逐项绑定原文。
2. 把候选展示和裁决格式先离线校验。复核者必须读到逐字候选、可匹配位置、端点类型及连续断言窗口；“没有候选”时仍需检查完整原文、补齐遗漏并区分负例与不确定。
3. 使用全新控制题和已知失败文献再做小样本双标、裁决及共同错误复核。引用位置格式有效率和语义判断分别计分；只要控制漏项、明显错误裁决或批量失败仍存在，就不恢复500条参考标注。
4. 对100条校准集按版本重建语义参考，原冻结标签保持不变；同时复核已选最终分区的范围和关系覆盖，不替换困难样本。
5. 重估剩余工作预算。当前309万余额不能被当作扩大总额的授权，不能在总上限外完成标注。
