# R2.1 跨度转移结果（页锚点 + 文本对齐）

日期：2026-10-31。补齐 R2.1 只交付到页码级的缺口：把冻结 M1 引用映射到重解析后的当前块与偏移。未新增模型调用，未修改语料或索引。

## 方法

`framework/knowledge_graph/span_transfer.py`（`span-transfer-v1`）按三级策略定位，全部显式记录方法与分数：

1. **页锚点**：从 `legacy_mapping` 取旧块的页码与该页候选新块，只在同页候选内搜索，避免引文"漂移"到别的页。
2. **精确匹配**：`str.find` 逐字命中 → `exact`。
3. **归一匹配**：去空白 + 标点折叠（保留到原字符的索引映射）后命中 → `normalized`。
4. **字符对齐**：`SequenceMatcher` 按匹配块覆盖率计算，≥0.90 才接受 → `aligned`。
5. **分段回退**：冻结引文常由多个块拼接而成，按句切成段分别定位，覆盖率 ≥0.80 记为 `segment`，0.50—0.80 记为 `partial`（不视为已映射，但保留位置）。

不可映射时明确返回空，不做"取最近"式的猜测。

## 结果

对 5 篇重解析文献的 **21 条**参考证据：

| 结果 | 条数 | 说明 |
| --- | ---: | --- |
| 完整映射 | **14** | exact 5、normalized 9 |
| 部分定位 | 5 | 覆盖率 0.34—0.72，多为跨块拼接或尾部表述不一致 |
| 不可映射 | 2 | 该页内容在新解析中已不存在 |

产物：`artifacts/knowledge_platform/retrieval-quality-r1/span-transfer-20261031-v1/span-transfer.json` 与 `summary.md`（本地证据）。

## 对 R1.4 的影响

同一冻结用例重跑（`r14-transfer-20261031-v1`，"引文无法定位"从 **7 条降到 1 条**）：

| 状态 | 转移前 | 转移后 |
| --- | ---: | ---: |
| `current_chunk_not_returned` | 17 | 23 |
| `quote_absent_from_current_parse` | 7 | 1 |
| `in_top5` | 0 | 0 |

也就是说：**转移解决的是"能不能定位"，没有解决"能不能排进前 5"**。原来 6 条无法定位的证据现在都有了当前块坐标，但它们仍未进入返回的 20 段窗口。

## 限制

1. **不能修补内容缺失**：2 条不可映射与 5 条部分定位，反映重解析后的文本与冻结版本存在实质差异（跨块拼接、措辞变化、个别段落缺失）。不据此改写引用，也不把部分定位当成完整映射。
2. **对齐是字符级**：`aligned`/`partial` 只证明字符覆盖，不证明版面正确或语义等价；双栏顺序问题不在本模块保证范围内。
3. **只覆盖 5 篇**：其余文献未重解析，仍沿用原块号，不做转移。
4. **审计留痕**：每条结果带 `method`、`score`、`coverage`、旧块/新块与偏移，可逐条复核。
