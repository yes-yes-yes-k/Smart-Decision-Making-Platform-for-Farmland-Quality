## 调用预留

| 项 | 值 |
| --- | --- |
| 请求数 | **10**（每篇一次，一次只发该篇的 8 个块） |
| 允许重试 | 每篇最多 1 次，仅限网络/5xx；最多 **20 次尝试** |
| 输入 token | 61,686 字符 ≈ **24,700—38,600**（按 2.5—1.6 字符/token 估算，含约 600 字符指令） |

相对此前授权：17 次查询嵌入（182 token）的量级不同，这批是**抽取调用**，输入输出都要计费，请按上表预留。

## 恢复点

- 每篇完成后写 `checkpoints/<document_id>.json`，记录 `attempt`、`request_sha256`、`usage`、`state`；
- 续跑时跳过 `state=succeeded` 的文献，只补未完成的；
- 请求体哈希不匹配则拒绝发送，防止提示词被改动后与已完成结果混用；
- 失败文献单独落 `failures.json`，不自动重试超过预留次数。

## 校验（R2.5 的验收口径）

1. 每条记录必须给出**原文精确子串**、块号与坐标，且该引用在块内唯一；
2. 实体先定位、关系后判定，端点必须来自已冻结实体（`selection_protocol_v2`）；
3. 拒收按原因码统计（错块、越界、歧义、跨研究、重复），不静默丢弃；
4. 通过只代表结构合法，`semantic_support` 保持 `unreviewed`，不产生已发布断言；
5. 输出写入临时候选区，不写 PG、不进活动 release。
