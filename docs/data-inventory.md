## 首版处理原则

- 当前仓库不复制大体量原始空间数据，只记录来源路径和接口所需元数据。
- 三普、二普和测土配方点位均按脱敏演示数据处理，不输出生产级定位结论。
- 首版接口优先返回稳定结构和来源说明；真实模型派生结果可在后续 change 中替换占位规则。
- 所有图层和诊断结果必须带 `source` 或 `lineage` 字段，方便未来 Agent 判断结果可靠性。
