# Cd 对话能力设计

本文件记录用户于 2026-11-03 最终确认的需求。对应 OpenSpec 变更为 `add-cd-conversation-capabilities`，实施进度见该变更的 tasks.md。

## 已确认范围

- 首期污染物为 Cd，提供统计查询、计算参数定义查询、地区参数值查询和参数计算。
- 目标地理层级包括省、市、县、乡镇和地块，实际结果受数据覆盖和统计规则约束。
- 八类通量均纳入目标，随后端就绪逐项交付。输入包括灌溉水、农业投入品、大气沉降和企业输入，输出包括粮食移除、秸秆移除、渗漏和径流。
- 总输入、总输出和净收支须说明分项覆盖，分项不全时提供已覆盖小计及缺项。
- 土壤总镉、土壤有效态镉、作物镉以及实测与预测类别须明确。优先沿用上下文，歧义未消除时追问，不同来源默认分别展示。
- 参数可自动使用地区、时期和适用条件匹配的已有值并展示来源。剩余必需参数集中追问，经验默认值经用户接受后使用。
- 单位未核验时可展示原始记录及状态，依赖单位的换算、通量计算和超标判断等待核验。
- 多轮计算沿用已确定参数，替换用户指定项并展示实际输入摘要。切换地区或年份时重新查询受影响参数，无法确定单位时追问。
- 试算默认保留在本次对话，用户明确要求保存后进入持久化业务记录，绑定地区、时期、输入来源和计算版本。

- 用户不指定时间时可查询已有数据并标注记录时期或时期未知。指定年份时须满足时间条件，无法筛选时询问是否查看时期未知的数据。
- 第一批接入土壤指标查询、作物及有效态 Cd 结果查询、模型参数查询和参数预测，同时提供八类通量能力清单与缺项回答。
- 保存完整试算记录。同一试算结果重复保存返回同一记录，修改参数并重新计算后保存生成新记录。
- 回答采用简短结论、结果表格、口径与来源，计算附实际输入摘要。

## 已确认的统计口径

土壤区域统计采用相交面积加权均值，返回有效地块数、有效面积和服务支持的最小最大值。Cd 预测结果采用记录分布统计，返回有效记录数、算术均值、中位数和最小最大值。

所有结果标明真实统计口径，并展示服务实际支持的统计项。按单位面积表示的通量结合适用面积换算后才能汇总为区域总量，汇总前校验单位、时期和空间覆盖的一致性。

## 实施顺序

1. 建立能力清单，描述支持的指标、数据类别、地区层级、时间条件、参数契约、单位状态和可用操作。逐项核验服务与数据覆盖。
2. 复用现有区域和地块解析、土壤统计及 Cd 服务，通过现有工具注册与执行链接入三类对话能力。不同来源按已确认规则分别查询展示。
3. 增加跨用户消息的参数草稿，保存已解析地区、时间、模型和参数来源。补参、替换参数与切换地区时按约定更新。
4. 按完整输入执行纯参数计算，返回可追溯结果。实现独立试算保存及幂等处理。
5. 对已就绪能力运行验收场景，逐项迁移八类通量服务并复用上述对话流程。

## 验收场景

| 场景 | 预期行为 |
| --- | --- |
| 查询某县某年度土壤总镉 | 使用对应年度快照，分别标明统计年度、实际测量年份及插补信息，展示真实统计口径和覆盖 |
| 查询各乡镇作物 Cd 预测结果 | 地区解析准确，不同来源分别展示，保留单位核验状态 |
| 只问某地镉含量 | 根据上下文确定指标与数据类别，仍有歧义时追问 |
| 查询指定年份但预测记录缺少时间 | 说明无法筛选该年份，询问是否查看时期未知数据 |
| 查询模型输入定义及地区参数 | 展示含义、单位、适用条件、已有值来源和缺失项 |
| 用户提供部分参数 | 仅自动补入条件匹配的已有值，其余必需参数集中追问 |
| 修改上一组参数重新计算 | 仅更新指定项，展示实际输入摘要及新结果 |
| 切换地区或年份 | 重新查询受影响的地区参数，处理单位歧义 |
| 查询尚未迁移的通量能力 | 返回能力缺项与原因 |
| 计算总输入但分项不全 | 返回口径一致的已覆盖小计及缺项 |
| 重复保存同一试算 | 返回同一业务记录，修改参数后重新计算可保存新记录 |
| 空数据、单位未核验或服务失败 | 明确报告对应状态，区分无数据、不可计算和服务异常 |


## 核查边界

当前仓库已将 Cd 预测、统计、空间服务和土壤 cadmium 指标接入普通聊天及 SSE。通量能力清单逐项报告接入状态，通量计算随后端迁移开放。

现有 Cd 批量结果写入按地块覆盖旧记录，试算保存需要独立记录语义。现有工具循环也不能直接代表跨用户消息的参数草稿。

原网站访问未成功，历史迁移文档记录的本地 AcidMap 路径在当前机器不存在。历史规划中的数据量与部署状态不作为当前运行事实。
