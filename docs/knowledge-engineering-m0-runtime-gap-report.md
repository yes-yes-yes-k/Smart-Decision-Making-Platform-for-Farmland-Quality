## 交付与核验方法

产物目录：`artifacts/knowledge_platform/recovery-m0-v1/`。

- `inventory-v2.json`：权威本机盘点；`inventory-v1.json`保留首轮成功结果，`inventory-default-v1.json`保留沙箱连接失败。失败快照不能用于资格绑定结论，其中eligible为空时的outside计数不具资格判定意义；脚本后续版本已避免此类推断。
- `processes-v1.json`：脱敏进程角色、选定监听端口与物理内存，不输出原始命令行。
- `runtime-config-v1.json`：运行时包、配置存在性与模型名称状态，不输出密码或令牌。
- `manifest-v1.json`：盘点文件及源码证据的哈希，记录已验证旧资产保持不变和预算只读结果。

关系库使用服务器强制只读、REPEATABLE READ、连接/语句/锁超时，并回滚关闭；向量库使用SQLite URI mode=ro与query_only，未启动Chroma客户端。默认沙箱连接失败后使用用户已授权的只读本机连接，未输出连接串或异常原文。模型调用为0。

后续仍待实测：API启动/检索可用性、HNSW健康、端到端延迟、运行内存峰值、单位抽取成本、OCR/表格语义正确性、十万篇容量。M0将这些列为缺口，不用模拟或历史成绩替代。
