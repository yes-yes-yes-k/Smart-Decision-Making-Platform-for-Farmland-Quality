# 抽取评测 v2 标注手册（待试标草案）

版本 `extraction-benchmark-v2-handbook-draft-1`。此文件尚未通过试标，不能直接发布正式参考。仅用于耕地/土壤领域既有四类实体、十类有向关系；本体文件为 `framework/knowledge_graph/schemas/minimal-cultivated-land-kg-schema-v1.json`。具体本体文件名以协议清单登记的现存文件为准。

## 可见材料与身份

标注请求只包含 sample_id、带哈希的 `chunk`/`document_title` 原始文本和本手册，不含旧答案、后端预测、采样层、其他样本答案。双标 A/B 不共享答案，裁决请求才可见两份提议。

正文和题名分别定位、分别评分。字符位置使用原始 Python Unicode 字符序号、左闭右开；片段必须等于 `text[start:end]`。出现序号从 0 开始，按原文本逐字、不重叠匹配计数。位置为提交的确定性坐标，序号用于校验，二者冲突则记录该项非法；不得替换为另一处同名片段。空白折叠、大小写变换、OCR 纠错、断词合并均不用于原始跨度绑定。若需兼容旧空白协议，必须另报兼容结果，不能混入严格主指标。

审核页允许查看源文件页，但主抽取参考只能标注后端实际可见的文字。视觉 PDF 中有而输入中没有的内容记解析损失，不能计模型漏抽取。双栏拼接无法确定语义时只掩码受影响的任务并注明原因；不能据此排除整个文档的其他可读内容。

## 实体清单与边界

- `indicator`：明确属于土壤/耕地质量的可测属性。土壤 Cd 含量属于该类；籽粒 Cd、植物富集系数、气象温度、算法 RMSE、仪器电导池常数均不能仅因是数值属性纳入。缺少介质时给 unknown，不用论文主题替代局部证据。
- `obstacle`：来源明确的土壤退化、污染或限制状态。裸元素 Cd 不等同于镉污染；泛指“障碍”不扩写为具体酸化、盐渍化。
- `measure`：田间管理、农业投入或土壤修复干预。消解/测定所用试剂、仪器、振荡、离心和校准液均不属于治理措施。材料名称在实验步骤中出现，不能靠常识推为田间施用；来源明确施用于土壤并研究治理/管理效果时才纳入。
- `standard`：明确具名的标准、规程或规范性政策。普通论文和期刊不是标准；“本标准”等泛指保留在指代记录中，只有可见输入明确锚定身份时才能链接，不把指代本身计入具名实体主清单。

选择最短可独立识别且保留必要修饰的实体片段，不含句末标点、数值或单位；物质与介质限定必要时保留。完整术语与缩写若分别出现，分别存 mention；是否同义由规范化任务另判。并列实体逐项标原文，省略的字不可补入跨度。

标准编号和标准全称在同一处共同出现时，分别存编号与全称两个 mention，不再额外存覆盖二者的整段 mention。只有编号或全称之一可见时只标可见者，不要求外部补齐。它们的等价关系需要可见身份证据。标准年份保留在编号表面形式中，家族隔离规则不改变实体表面形式。规范性引用可以标具名标准，但引用本身不自动支持其规定的关系。

重复提及均可存储，重复相同位置/类别非法；主实体清单按“正文/题名、类型、逐字表面形式”去重，另报位置诊断，不把出现多次当多个独立概念。类型争议保存替代项和裁决，不简单删除实体。

## 分开的输出字段

每个实体保存 `id/type/block_id/text/start/end/occurrence`，以及类别支持引文；`normalization` 独立保存 status、canonical_name、等价引文、端点 ID。规范化未知不能删除字面正确实体，不能凭常识扩写缩写。题名身份可用于标准链接，但证据必须明确标为题名，不能移到正文位置。

每条关系保存 `type/source_id/target_id/modality/conditions/evidence`。关系端点必须已有有效 mention，方向遵守冻结本体。引文存 block_id、逐字文本、起止位置及支持作用，分别区分身份锚点和关系断言；只有身份锚点不足以证明关系。

关系候选模态：asserted、normative、hypothetical、negated、unknown。主正例只纳入来源明确支持的 asserted/normative；可能、研究目的、无显著改善均不能计改善正例。保留否定和不确定判断作为负例审核记录，不把 negated 变成反向肯定关系。

## 十类关系

| 类型 | 方向 | 最低语义证据 |
|---|---|---|
| addresses | measure → obstacle | 实际治理、缓解或明确规范性推荐，不只是研究目的 |
| improves_indicator | measure → indicator | 明确有益变化；任意增加/降低不等于改善 |
| characterized_by | obstacle → indicator | 指标明确表征该障碍，不能只共现 |
| includes_indicator | standard → indicator | 正文明示纳入评价，引用标准名称不足 |
| prescribes_measurement | standard → indicator | 规范测定该指标，主体可由题名身份锚定 |
| assessment_basis | standard → obstacle | 标准为障碍/状态提供判定依据 |
| classifies_basic_indicator | standard → indicator | 明示基础性指标分类 |
| classifies_regional_supplementary_indicator | standard → indicator | 明示区域补充性指标分类 |
| assigns_by_field_survey | standard → indicator | 明示据实地踏勘赋值 |
| assigns_by_laboratory_test | standard → indicator | 明示据实验室检测赋值 |

未满足已有本体的事实保留 out_of_schema，不为凑关系覆盖强行映射。联合干预有效不代表每个成分独立有效；土壤酸度降低是否改善必须依据来源条件，不能盲用数值方向。证据只支持单句时，不拼接另一个文档的题名构造因果关系。

## 质量、排除和裁决

每个任务分别保存 `applicable/unknown/excluded` 及来源原因；质量描述是诊断字段，不能跳过实体和关系任务。解析失败/信息不足固定在参考掩码，难抽取、模型超时或输出截断不属于参考排除理由。参考没有关系与关系任务不可评必须区分。

逐项裁决旧新边界与 A/B 差异，包括漏项、错误类型、方向、位置、规范化、条件和证据。裁决可选择 A/B、另写有证据的修订或 unknown，必须有原文理由，禁止简单投票。一致项也抽查并记录共同漏项；同模型两个独立请求不是独立专家。

开发侧 10 条实际来源与独立控制题一起验证。本手册列出的关键边界须无未决规则冲突，全部差异有来源裁决或明确任务级未知，跨度/序号可重建。输出实体清单、关系、排除、证据的一致性及各自支持数，同时列出共同错误。未达到条件则继续修改草案并用新的开发验证材料检查；不得借用最终题调手册。
