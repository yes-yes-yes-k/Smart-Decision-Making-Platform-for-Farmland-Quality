# v4 标注手册与统一输入契约（AI 校准版）

版本：kg-evaluation-v4.0。用户授权 AI 双轮标注及裁决；不是专家双标，不能据此认证生产准确率。

## 可见输入

标注者和被评系统均只能看到 `sample_id` 和 `blocks`。`chunk` 是冻结分块正文；`document_title` 是数据库原有题名，独立作为文档身份上下文。每块保存 kind、原文及 SHA。不提供 v3 标签、质量判断、模型预测或采样分层。

字符位置采用原始 Unicode 字符序号、左闭右开，不是 UTF-8 字节、token 或规范化字符串位置。模型提交逐字片段和从 0 起的出现序号，程序定位 `text[start:end]`，不会自动改写 OCR、扩写缩写或猜测原文。多次出现时必须明确所指；不得将另一处同名实体当作关系端点。

## 三个独立任务

### 原文实体 mention

每个实体 occurrence 保存 id、type、fragment(block_id/text/occurrence) 和判断理由。中文不强制加“土壤”前缀；英文保留原文缩写和大小写。协调省略只标原文可见片段，恢复概念留到规范化。多个真实 occurrence 可以保留，完全相同跨度和类型禁止重复。

- indicator：土壤/耕地质量可测属性，含明确上下文中的元素含量、孔隙度、生物属性；植物/水体/产品指标不因同名而入选。
- obstacle：明确的土壤退化、约束或污染状态，裸化学元素不是障碍。泛指“障碍特性”仅在正文明确作为土壤约束时可标，不能与具体污染类型等同。
- measure：实际农业、土壤管理或修复措施；联合处理整体作为实体，不把联合效果拆给成分。实验试剂、测定仪器、数学模型不是田间措施。
- standard：具名标准/政策。编号或完整政策名称均可；仅泛称“本标准”时可标其 mention，规范化身份只能来自可见题名或本块明确编号，不使用外部知识。

标题中的具名实体可以标，但须标 `context_entity=true`，不混入正文 mention 指标。参考文献书目标题不当作本块事实来源；明确规范性引用可以标标准实体。资料不足、类型不明写 notes，不强行填充。

### 实体规范化

canonical_name 与原文 mention 分离。仅可见输入明确给出等价关系时才标 normalization_status=known；否则 unknown 且 canonical_name=null。不能仅因常识或题名研究主题就把 RS 等缩写扩成某材料。命名一致性不证明实体链接正确，本次不发布专家认证 canonical registry。

标准主体若只在题名出现，标题名实体，并在关系证据中同时指向文档身份片段和正文条款。不要将不存在的标准编号填入正文 mention。

### 有向关系与证据

端点引用已标 mention ID；方向必须满足既有 schema。模态分 asserted（陈述事实）、normative（规范推荐/要求）、hypothetical（可能/目的/假设）、negated、unknown。主正例关系指标只计 asserted/normative，其余单独审查，不把“could improve”“研究其效果”“无显著改善”变成改善正例。

improves_indicator 要求明确有益效果，不是任意升降；addresses 要求治理/缓解；characterized_by 要求指标与障碍的表征联系；prescribes_measurement 是标准对指标测定的规定，端点是指标，不是把实验室方法标成措施；assessment_basis 是判定障碍的依据。includes_indicator 仅在明确纳入评价时使用，不因测过某指标就自动加入。基础/区域分类、实地/实验室赋值只有显式条款才标，不把“基本检测项目”当基础性评价分类。

默认标最具体关系，不额外推导所有上位关系；评测报告应单列粒度兼容诊断。前人研究的明确陈述可以标，但保留来源语气；纯书目标题不标关系。必要的短因果链须写理由，无法由输入支持则 unknown，不推导外部机制。

每条关系提供最小充分证据，可由多个原文片段构成，例如题名身份加正文谓词、指代前件加效果句。证据必须逐字定位，但不要求两个规范名出现在同一短句。短且充分优先，整块引用需要说明为何无法进一步缩短。位置校验不是语义充分性的替代。

## 质量与穷尽性

A=本任务信息完整，B=部分可读/跨栏/表格错位/上下文不足，C=无足够可判断信息。entity_eligible、relation_eligible、numeric_eligible 分别判断；C 全部为 false，不能当正确负例。B 可实体可评但关系不可评。numeric_eligible 仅作后续数字任务标记，本轮不声称评了数值抽取。

completeness.entities/relations 分别说明是否能够穷尽本任务。能够读懂且确实没有本体事实才给完整空集；不确定时记 false 和原因，不能靠空数组冒充负例。正文与题名的实体覆盖分开报告。

## 校准流程与门槛

100 条来自开发集的固定样本（77 个文档组），5 个诊断层各 20 条。A/B 收到相同输入且互不查看结果，原始响应、错误和有限修复保留；裁决需同时看原文及两份标注。两份结果即使同模型一致也不视作独立正确性证明。

预设扩大门槛：全部样本处理完成、位置绑定全有效；mention/span+type 双标 F1 ≥0.90，正例有向关系 F1 ≥0.85；争议有明确裁决或 unknown；正文/题名分层与来源质量分别报告。空集不作为“100%关系一致”来抬高 F1。自动裁决不能消除 AI 的相关偏差。门槛通过也只允许继续开发参考构建，不能批准生产或专家金标。

## 发布状态

1,000 个 v4 来源只冻结新输入，旧 v3 标签不自动迁移。校准裁决结果写入新文件；未完成样本保留 unannotated。只有满足本任务契约、校准和全量复核后才能形成完整 AI reference。独立专家认证、新盲测与生产资格继续单独记录。
