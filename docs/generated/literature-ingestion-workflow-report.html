01 · 改造概览

解决了什么问题

原有链路适合零散 PDF，面对 PDF、扫描件、CAJ、压缩包和结构化清单混合的千份级资料时，缺少批次治理、审核、恢复与质量追踪能力。

一句话总结

建立“接收—审核—处理—发布”的统一文献流水线

  • 入口统一

    管理员批量导入与用户单篇上传，共用同一处理核心。

  • 过程透明

    阶段、进度、错误、重试和审核记录均可查询、可审计。

  • 发布可控

    管理员确认标签并审核后，文献才进入公共知识库。

05 · RAG 规范引用

从“文档1”升级为可核验论文引用

本次对话继续完善了检索增强生成的回答格式：正文按首次出现顺序标注 [1]、[2]，末尾输出接近 GB/T 7714 的参考文献，并用真实知识库查询完成端到端验证。

BEFORE · 原有表现

“根据文档1、文档2……”

引用仅对应检索结果序号，读者无法直接判断论文题名、作者、来源、年份或 DOI，回答的学术可读性和可追溯性不足。

AFTER · 当前表现

正文编号 + 规范参考文献

回答正文使用连续编号；同一论文的多个分块共用一个编号；末尾按实际元数据生成题名、作者、期刊、年份、卷期页码和 DOI，不臆造缺失字段。

01

补齐检索结果书目信息

对旧向量分块回查数据库元数据，并在新入库向量中保存作者、期刊、卷、期和页码等可用字段。

兼容旧数据元数据增强
02

统一引用生成规则

流式与非流式回答使用相同规则，禁止“文档1/2”占位称呼；多分块命中同一论文时自动去重并保持编号稳定。

流式一致稳定编号
03

输出学术参考文献

根据文献类型生成接近 GB/T 7714 的条目；标准使用 [S]、期刊论文使用 [J]，信息不完整时保留真实题名或文件名，不猜测作者与刊物。

GB/T 7714 风格禁止臆造

问题：土壤酸化有哪些治理措施？

deepseek-ai/DeepSeek-V4-Flash

土壤酸化的治理措施主要分为“酸化阻控”与“酸化治理”两类，需结合施用土壤调理剂、合理施肥和农艺措施综合实施。

  1. 分类防治：酸化阻控包括配方肥、缓控释肥、稳定性肥料、化学碱性肥料，以及有机肥、绿肥压青和秸秆促腐；酸化治理则通过调理剂改善土壤酸度、提高 pH。[1]
  2. 按酸度选材：强酸性土壤可使用石灰石粉配合有机肥；中酸性土壤可使用石灰石粉或 CaO 型调理剂；弱酸性土壤可施用硅钙钾镁肥与有机肥。[2]
  3. 综合模式：可组合石灰降酸、钙镁磷肥、有机肥阻酸、秸秆还田、减氮控酸和冬种绿肥。[3] 轮作休耕等农艺措施也可纳入治理。[4] 坡耕地还可采用石灰、有机肥和测土配方施肥协同改良。[5]

06 · 增量知识图谱

论文上传后，图谱可以自动增量更新

当前方案不要求从零开发完整图数据库产品。系统以统一领域契约隔离底层实现，复用 Apache AGE 作为生产图存储，并保留 JsonGraphStore 回退；GraphRAG、OpenSPG 作为候选抽取 adapter，必须通过同一套一致性和金标评测后才能进入生产。

设计边界 · 不做什么

不把开源产品直接当成业务真相

开源组件负责图存储、图查询或候选抽取，但实体类型、关系方向、证据定位、审核规则、版本发布和权限仍由本系统统一定义，避免被单一厂商格式锁定。

当前方案 · 如何复用

领域契约 + 可替换 adapter

统一 Entity、Relation、Evidence、Release 与 GraphQuery 契约；底层 adapter 可替换，所有候选先进入审核区，只有证据完整、方向有效且通过发布门禁的数据才能进入活动图谱。

01

完成领域模型与关系约束

固化实体、关系、证据、候选和 release 契约，校验关系端点类型、方向、证据原文、页码、分块与内容哈希，禁止仅凭共现生成生产关系。

方向约束证据定位不可变审计
02

接通上传后的异步任务

文献完成发布后通过事务 outbox 创建幂等抽取任务；支持租约、重试、死信、worker 崩溃回收和重复投递复用，不回滚已经成功的文献与向量索引。

Outbox幂等任务崩溃恢复
03

建立候选审核流水线

仅从已发布、带页码的当前分块抽取候选；完成实体消歧、关系合并、跨文献证据聚合、风险筛选和人工批准/拒绝，禁止直接写生产边。

候选区人工审核跨文献聚合
04

完成版本化发布与回滚

实现 release 差异预览、校验和、发布门禁、原子 active_release 切换和已验证版本回滚；历史关系使用有效期保留，审计导出可复现。

Release原子切换一键回滚
05

接入图谱 + 向量混合检索

图查询限制在一至两跳和 top-k 范围，图证据最终仍回到权限过滤后的文献分块；图谱、adapter 或发布异常时，向量检索继续可用。
