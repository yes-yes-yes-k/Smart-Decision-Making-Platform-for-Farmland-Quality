## 尚不能开展的环节

新试标、双标、裁决、关系支持确认、基线校准和最终验收均未运行。既有 API 暂停继续有效，未探测恢复。当前共享账本仍为 293 次尝试、989951 token 实际用量或保守预留之和（非实际账单），没有重置消耗，inflight=0。

旧稳定性阶段剩余 11164 token。按当前草案完整手册、10 条来源输入以及单次 4096 输出上限估算，预留量为每次 13012–14866，单次都超出旧稳定性余额。此为未来请求配置的本地预算预检示例，不是实际消耗；恢复 API 也不能自动绕过阶段上限，需要明确后续预算安排。项目总剩余为 9010049 token 和 4707 次尝试，不代表可以突破阶段限制。
