# 知识工程现状与决策树

日期：2026-10-30。状态：九项设计边界与整体恢复计划已获确认，M0只读运行盘点及OpenSpec范围整理已完成。不开展新评测集、模型批次、生产发布或架构切换。

## 目标与已查明的偏差

用户的目标是建立可容纳六位数论文的知识图谱。原平台提案已将至少100,000篇文献、100,000规范实体、1,000,000条关系证据定义为容量基线，而非首期必须一次性导入的数量。当前仍需澄清首要用户用途，以及文献容量、抽取覆盖和发布质量是否分开验收。

目前工作主线偏向参考集修复、标注协议与外部评测。有效外部评测OpenSpec明确不写生产数据库、索引或图谱，因此它的完成不代表生产图谱随之建成。这是工作范围与总体交付之间的缺口，不能再用扩大评测填补。

事实来源：`openspec/changes/incremental-literature-knowledge-graph/proposal.md`、`openspec/changes/rebuild-graphrag-extraction-benchmark/proposal.md`。

## 关键诊断（待事实调查补充）

1. 文献收录、语义提取、实体归一、断言审核、发布查询及规模运行是不同交付，不能用一个“图谱完成率”替代。
2. 外部基准当前能提供能力诊断，不能直接充当中文土壤领域的生产资格证明。
3. 原文中带土类、剂量、时长和试验条件的结论，不能未经确认就压成无条件关系。例如“某剂量生物炭在酸性红壤培养90天后提高pH”，与“生物炭普遍改善土壤”不是同一断言。
4. 首期所有新事实逐条人工审核的既有规则，与十万篇目标之间存在人力规划问题。用户此前表示没有可参与专家；不能默认AI复核等于专家，也不能未经确认取消审核。
5. 近期工作的资源配置应回到可持续运行和用户价值；评测只对明确的失败风险提供必要验证，不应持续成为独立交付主体。

## 决策树与当前前沿

已确定：目标至少十万级文献容量；当前停止盲目开发评测；维持已授权预算和生产边界；不以AI一致性宣称专家认证。

第一轮已获用户确认：

- D1 首要用户用途：优先文献证据检索与比较，图谱服务于该用途。
- D2 覆盖与交付：分别验收文献容量、抽取覆盖、已验证发布断言量，允许首期部分语义覆盖。

第二轮已获用户确认：

- D3 最小研究任务：首期以“某土类/条件下，措施对指标的影响与论文证据对照”为范围，保留矛盾与条件，不自动归纳普遍因果。
- D4 候选可见与发布边界：允许未审核候选只用于内部召回和原文定位，并明确标注；已审核发布断言单独治理，保留当前生产门禁。此为已确认的目标设计，当前代码并未因此改变，也未获得候选直接发布授权。

第三轮已获用户确认：

- D5 对照记录：论文与原文位置、措施、指标、结果表述、原文明示的土类/试验条件；剂量、时长、效应值和单位有则保留。缺失未知，保留否定与不确定性，不补猜或直接跨条件数值汇总。
- D6 抽取范围：集中于支撑该对照任务的研究记录，其余内容仍全文可检索，不追求所有论文所有实体关系抽全。
- D7 交互方式：同步返回文献检索结果，跨论文对照单独发起，可异步生成和有效结果复用；具体延迟/成本目标待实测后确定。

第四轮已获用户确认：

- D8 首期允许全文/向量来源检索先提供可追溯结果，图谱作为可选辅助召回；继续建设文献、研究记录和断言的关联，不要求每条查询必须经过图谱。
- D9 首期新增研究断言保持待审，仅辅助召回和有原文支持的对照，不新增已确认知识发布；既有已审断言保留。AI复核不自动具有专家认证，也不构成生产发布授权。

后续收敛近期里程碑与整体验收范围。性能/成本以现有资源实测后提出目标，不擅自提高现有预算、承诺工期或将某个专项账本余量转为新用途预算。具体可逆实现选择由后续方案提出，不要求用户逐项选择工具与库。

尚不作决定：更换图数据库、引入新框架、全量重抽、扩大模型预算、追加新金标或最终外部评测。候选召回与已发布断言的信任边界已获确认并记录ADR；这不是对产品实现范围的最终批准。

## 整体理解确认前的候选计划

九项业务/设计边界与整体计划均已获确认，用户已授权从M0实施；M0实测见`docs/knowledge-engineering-m0-runtime-gap-report.md`，对应OpenSpec为`enable-literature-evidence-comparison`。后续性能和费用数值依赖只读盘点及有界实测，不在本轮猜测。

先盘点当前运行链及真实闭环缺口，在十篇现有文献完成检索、研究记录、候选状态、证据对照和撤回失效的可观察交付；新增断言保持待审，不为演示而发布。既有发布/回滚能力作为独立回归检查，不将本轮候选闭环冒称原AGE发布试点已完成。随后以真实分块/断言规模推导千篇持续运行、10k与100k容量验证。

对照实验只针对妨碍所选用途的具体风险，复用已有诊断材料，不默认另建大规模评测集。最终实施范围需在后续问答达成共识后确认。
