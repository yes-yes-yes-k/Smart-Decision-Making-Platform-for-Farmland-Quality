# v4 AI 试标发现的规则澄清（不追改已运行提示）

下列问题来自首批 10 条原文复核。原手册和 r2 提示哈希保留，不用新规则悄悄重算旧一致性。下一次校准采用新修订号，并保持两组可见输入相同。

1. **eligibility 与是否存在事实不同。** 文本清楚且没有本体关系，relation_eligible 应为 true，关系为空；仅在输入不足以判断时为 false。不可用关闭 eligibility 隐藏漏标。
2. **题名主要提供文档身份与显式 mention。** 题名是“某修复材料制备规范”不能直接推出材料已经缓解障碍；题名与正文的实体和关系支持分别记录。
3. **分析物所属介质必须核查。** 土壤有机碳测定标准中的葡萄糖校准液有机碳，不自动成为土壤有机碳观察值。检测方法不变成田间措施，沸水提取不是治理措施。
4. **定性描述与可测指标区分。** 土壤肥沃等泛化描述不能一边说明不是可测指标一边标成 indicator；若要接受土壤肥力概念，须定义其具体边界，不能根据当前预测修改规则。
5. **OCR 与规范化分离。** 有效确等 OCR 字样不得静默修正引用；正文有其他有效硼片段则引用其原文。原文不可充分确定时标 unknown/不完整，不能发明修复后的 quote。
6. **重复 mention 与重复事实区分。** 正文编号、正文全称和题名全称是不同 occurrence，可单独计 mention；同一有向事实及模态不要复制两次，多个证据合并到同一事实。
7. **无关主体或方向不通过时不得反转事实凑 schema。** 需要重标端点类型，或放弃不支持的关系。

当前两组只共同通过 2/10 条结构与来源校验，且原文复核仍发现共同语义问题。此结果不够估计标注准确率，也不支持给完整校准集或参考集加“已完成裁决”状态。剩余 90 条保持待标，原 1,000 条保持迁移队列。
