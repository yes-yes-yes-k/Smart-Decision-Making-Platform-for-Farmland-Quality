## 主要问题与证据

### 解析文本稳定，但部分内容顺序和文本层错误

449的摘要/Significance和双栏正文、1149的双栏正文被逐行混排。1141页4/5还有页外旧稿文字及重复字形；可见PDF正文与导出文本不同，例如正常65.2%附近的旧分块出现`46o5f.213%`。重解析得到相同分块只说明稳定复现，不能说明文本正确。

修复应在R2.1形成新的解析/分块版本及位置映射。旧跨度继续绑定旧版本，不通过清洗后字符串相似就把旧拒收改为有效。1021/1032为原生CAJ，转换所得页映射尚未独立复查，保留原件可访问性与派生文本可信度的区别。

### 旧失败有明确定位原因，不能以单一通过率解释

29条模型选择仍为2条定位合格待审、27条拒收。12字段/条共348项，244项为null，104项非空：

| 字段诊断 | 项数 |
| --- | ---: |
| 指定块中唯一精确匹配 | 54 |
| 指定块内重复，位置歧义 | 7 |
| 指定块不匹配，但别块有精确原文 | 4 |
| 空白/换行变化 | 8 |
| 跨行摘录删除原稿行号 | 20 |
| 双栏、文本层或断词重建，需逐项解释 | 11 |

以上按字段互斥计数，不能相加解释为27条记录的失败比例。精确匹配仍可能语义不支持；诊断恢复的跨度仅用于归因，未改变旧记录身份。实际请求内层JSON可完整还原原分块，未发现JSON序列化损坏原文的证据；删除行号、改空白等是输出选择与原始跨度协议不一致。

### 六篇空输出需按文献性质及抽样范围处理

六篇均有全文结构盘点和主要任务相关章节审读，保留19处主线索，其中13处未发送给首轮模型；308另有7处方法审读线索。它们是错误分析线索，不是26条新增事实金标。

- 104包含粪肥对容重、持水、气体传输/Ksat的结果及土类/作物差异，空输出不能解释为没有相关研究结果。
- 1021包含淹水/落干下金属形态变化；须区分实测与模型、金属种类及层位。非淹水表征/校准部分仍有未读范围，不能泛称全论文没有其他证据。
- 1032包含分区建议及钙质措施/水分管理的引用性描述，不能当作该论文新做的干预试验。原文比例与计数、章节/图注有不一致，暂不采用争议数字作验收答案。
- 1015为玉米—沉积物Pb模拟及验证，不能改写成稻田Cd改良效应。全部22块已读，图和方程仍需原件核实。
- 306为管理措施综述，保留原引用及正反、不确定结果，不合成为同一新实验。
- 308主要讨论土壤质量指标、方法、阈值及评分。窄措施—指标—结果契约可能合理返回空；不能为提高抽取数量硬造干预事实。反向表格等不可可靠理解部分保留未决。

首轮只发送80/1306块，未覆盖段落与已看但未选择必须分开。当前没有完整、可靠的事实分母，本次不报告抽取召回率，也不承诺再跑模型即可解决覆盖问题。

### 三条读取路径尚未统一

当前代码已有实体/关系/Claim候选及证据持久化；Claim发布审计不等同于Claim已写入可查询图。发布GraphStore路径仍只执行实体和关系写入。研究证据搜索走词法路径，没有接入可选graph_lookup；聊天读配置文件图，图API另读配置GraphStore。静态能力与真实运行数量分别记录。

R1应先建立实际词法/向量混合检索基线；R2.6/2.7再验证持久候选、条件及证据关联能被重启后的实际接口读取。图增益不能由实体/关系数量、路径存在或静默回退证明。

### 当前启动和迁移入口不能直接作为部署检查

`create_app`会执行多组DDL；导入依赖还会初始化Chroma。`--init-db`不控制这些全部副作用。已有研究迁移CLI只允许旧M1隔离SQLite路径；其他迁移CLI会先调用完整应用。当前尚缺适用于选定PG目标的最小显式迁移入口。

R3.1已给出最小初始化改造、数据目录隔离、跨存储一致备份、隔离恢复、幂等迁移与切换回退顺序；相关命令需等真实入口和目标准备完成后产生。旧备份存在不代表当前备份/恢复通过。
