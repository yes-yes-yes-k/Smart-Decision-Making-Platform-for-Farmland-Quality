# r4 统一提示与四任务拆分：新控制和原10条验证

日期：2026-10-27。已执行用户要求的流程改动与两类验证，结果仍未达到扩量条件，剩余90条未提交。本轮没有改抽取后端或覆盖历史标注。

## 协议变更

系统提示统一为中性任务说明，不再包含“只回答一个判断/只有answer字段”等与完整标注冲突的限制。四个任务分别输出：

1. 来源质量：只判断实体/关系任务的可评程度，不同时生成grade和eligibility；本地推导这些字段。
2. 实体：只返回原文mention、类型与理由，不生成规范名或规范化状态；本地分配mention ID。
3. 规范化：只返回有显式同义/缩写证据的映射；未映射项本地保持unknown/null，不能产生两者矛盾。
4. 关系：只从类型方向合法的端点组合判断事实与模态，不更改实体、规范化或质量。

规范化任务失败不删除已定位实体，关系判断可以继续；保留任务状态、原始响应、部分结果和来源跨度。输出字段已分开，但执行仍有依赖：质量C会跳过实体，实体失败会阻止下游；本轮验证证明前者存在风险，不能把“拆分字段”说成消除了所有流程耦合。

## 新控制验证

在调用前冻结11个新合成控制，各重复两次，全部正确才允许正常复测原10条。覆盖可读空集、乱码、土壤/校准液介质、实验室操作、显式别名、肯定/否定、题名身份、规范要求及英文属性。

22份输出中19份形成结构完整结果，严格控制判分仅 **3/22通过**。该分数针对多任务完整标注，不能与前一轮单项判断33/34直接横比。

原文复核发现，4次改善/否定关系的谓词和模态正确，但实体跨度包含“该土壤的”，违反预先固定的边界规则。这4次单列为边界偏差，不称为关系语义错误，不改原分或放宽门槛。其他失败包含：

- 将可读的会议、校准液或试剂段落判为C，并写“没有土壤事实，所以无法判断”；混淆不相关与不可读。
- 把泛称“土壤”或“Laboratory water”标成土壤指标。
- 将全称与缩写合成一个mention，未形成所要求的显式别名映射。
- 忽略题名里的标准身份，因正文无目标事实而跳过后续任务。

证据：`artifacts/knowledge_platform/gold-v4/calibration/r4/controls/`，含冻结protocol、原始响应、gate和boundary-audit。资格门槛保持false。

## 原10条诊断复测

用户明确要求验证新控制与原10条，因此在控制未通过后，另行执行标为 **diagnostic-only** 的原10条A/B复测。它不是正常放行的合格试标，配置记录该偏离，最多每任务一次请求、无修复，不具有启动90条的权限。

| 可保留实体mention | 9 | 12 |
| 肯定/规范关系 | 0 | 0 |

两组共同结构完整2条，原始mention集合一致性F1约76.19%；这是输出一致性，**不是准确率**。8个共同匹配mention中，5个是材料制备的改性、混合、液滴生成、分离和干燥流程，两组都误标为田间措施。高一致性不能消除共同类型错误。

A把含明确标准编号的前言判成C，跳过实体，B则正确保留标准；再次说明自动质量路由会隐藏漏标。英文DNA实验段落、抗菌素耐药性片段和题名上下文仍有范围争议，没有把不确定样本发布为负例或金标。

## 本轮协议遗漏及单独审计

新拆分提示没有明确说明 `occurrence` 是同一片段在同一文本块中的 **0起出现序号**。这是实现准备中的遗漏。模型有时把它当1起序号或mention列表序号，导致本来存在的原文被错误位置拒绝，不能全部归因于模型虚构。

原始实体响应的片段级审计发现：

- 85个失败片段的文字存在，但提供的出现序号无效。
- 12个片段即使按首次出现也无法在可见原文定位，涉及OCR恢复、改写等另行复核。

上述是片段数，不是样本数；没有自动改序号、恢复失败样本或重算分数。下一修订 `annotation_tasks_r41.py` 已在所有阶段提示和fragment schema里明确0起、每种text独立计数、不是列表索引，并加测试保护历史协议不被改写。该修订尚未做模型调用，不能宣称模型已执行正确。

## 验证与真实限制

21项相关测试通过，包括字段隔离、局部失败保留、原文和别名证据、正确短引用、空集/未知处理及新序号说明。两个模型实验组与全部控制进程已结束。

本轮已报告token：控制25,534，诊断A21,269、B25,390，合计72,193；实际费用未知。所有历史来源及成绩保留，v4新金标和生产批准仍为0/false。

## 决策

不运行剩余90条，不因字段冲突归零或边界可解释就宣布合格。下一轮应先验证明确的片段序号协议，并将“可读性”与“是否在本体范围内”分开：质量结论先作待审信息，不能直接凭“无本体事实”关闭任务或阻断实体提取。同时校准材料制备与田间措施边界。修订后仍须用新的控制与原10条复测，全部技术、语义和一致性条件通过后才允许扩量。
