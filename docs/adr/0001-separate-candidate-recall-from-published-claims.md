# 区分候选辅助召回与已发布断言

2026-10-30，用户确认首期服务有条件的文献证据检索与比较，并将文献容量、抽取覆盖和发布断言量分开验收。未审核抽取候选允许仅辅助内部召回和原文定位，明确保留未审核身份；只有审核发布的断言作为已确认图谱知识，回答仍须逐项引用原文，既有生产发布门禁保留。

该边界避免把逐条审核全部论文的工作量设为文献检索可用的前提，同时承担未核验线索可能产生误召回的代价。后续实现必须保留来源、状态和可追溯性，不能因候选被召回或被模型复核就隐式提升为已发布事实。该决策不授权扩大数据可见范围、修改权限、自动发布候选或宣称专家认证；产品实现尚待整体方案确认。

同日用户进一步确认：首期新增研究断言一律保持待审，仅辅助召回及有原文支持的对照；现有已审断言保留，不新增已确认知识发布。当前不引入AI自动审核发布规则。
