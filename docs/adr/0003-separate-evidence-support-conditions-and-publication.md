# 分开表达证据支持、条件明确性与知识发布身份

2026-10-30，用户确认保留主题相关但尚未找到直接支持段落的文献，并明确区分直接支持、背景相关和条件不明。决定将证据对研究子问题的支持程度、研究条件是否明确或吻合、研究记录是否审核发布作为三个独立判断：不能把“条件不明”放进与“直接支持”互斥的单一分类，也不能由支持判断提升候选的发布身份。

例如，原文可以直接支持“施石灰后产量无显著变化”，但没有给出用户所要求的土类；此时可保留对产量结果的支持，同时说明土类未知，不能称为满足该土类条件的结论。未找到支持片段的相关论文可以作为背景材料保留，不能据此断言全文无证据或措施无效。

该决策使状态表达与验收比单一“相关/不相关”标签更复杂，但避免把未知条件、主题相关和已确认事实混为一谈。AI初审须保留其核实方式和未决项，不能视作专家认证。既有候选/发布边界继续遵循[ADR-0001](0001-separate-candidate-recall-from-published-claims.md)，检索与对照的边界遵循[ADR-0002](0002-source-retrieval-before-graph-dependent-comparison.md)。本ADR记录已确认的领域规则，不指定数据库、接口字段或自动判定模型。
