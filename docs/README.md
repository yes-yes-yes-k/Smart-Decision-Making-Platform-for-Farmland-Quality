# 文档索引

本目录只保留当前可维护的接口、数据、部署和运维文档。历史实施计划、验收记录与已完成的 OpenSpec 变更由 Git 历史保存，不再重复留在工作树。

- `api.md` / `api-contract.md`：HTTP API 与返回契约。
- `openapi.json`：可导入 API 工具的 OpenAPI 规范。
- `deployment/` 与 `../deploy/deployment.md`：部署资料。
- `operations/`：运维手册。
- `data-inventory.md` / `field-mapping.md`：数据资产与字段映射。
- `../openspec/specs/`：当前生效的能力规范。
- `../openspec/changes/`：仅保留正在进行的变更。
