# 耕地质量模型集成修改规范（致模型提供方）

> **文档版本**：v1.0  
> **发布日期**：2026-07-28  
> **文档性质**：本规范是三个独立模型合并入统一项目前，各模型提供方必须遵循的修改要求  
> **适用对象**：
> - 模型A提供方：耕地质量等级和障碍度评价模型（Fortran exe）
> - 模型B提供方：耕地质量稳定性与退化风险识别模型（模型1）
> - 模型C提供方：耕地质量评价与障碍诊断模型（模型3）

---

## 一、修改背景与目标

### 1.1 背景

三个模型当前由不同团队独立开发，存在**指标命名不一致、数据接口不统一、功能边界重叠、区域配置冲突**等问题，导致无法直接串联运行。详细问题分析见 [model-integration-analysis.md](file:///d:/17417/Documents/agent_culti_demo/docs/model-integration-analysis.md)。

### 1.2 集成目标

```
统一数据层（标准命名）
        │
        ▼
   ┌─────────────┐
   │  模型C(模型3) │ ← 唯一的质量评价引擎
   │  质量评价     │
   └──────┬──────┘
          │ 输出: 隶属度/权重/综合指数/等级/障碍度
          ├──────────────────┬──────────────────┐
          ▼                  ▼                  ▼
   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
   │  模型B(模型1) │    │  模型C(模型3) │    │  模型A(exe)  │
   │  稳定性评价   │    │  障碍诊断     │    │  (备选/兼容)  │
   └─────────────┘    └─────────────┘    └─────────────┘
```

### 1.3 修改原则

| 原则 | 说明 |
|-----|------|
| **统一命名** | 所有模型采用同一套指标字段命名 |
| **接口标准化** | 输入输出格式、字段名、数据类型统一 |
| **功能不重叠** | 质量评价由单一模型负责，其他模型不得重复实现 |
| **可配置优先** | 权重、阈值、区域等参数必须可配置，不得硬编码 |
| **可测试** | 提供标准测试数据集和预期输出 |

## 二、统一指标命名规范（所有模型必须遵循）

### 2.1 标准指标字段名

**所有模型的输入、输出、内部代码必须统一使用以下字段名：**

| 标准字段名 | 中文名称 | 单位 | 数据类型 | 取值范围 |
|-----------|---------|------|---------|---------|
| `PH` | pH值 | 无量纲 | float | 3.5 ~ 10.0 |
| `YJ` | 有机质 | g/kg | float | 0 ~ 80 |
| `YXP` | 有效磷 | mg/kg | float | 0 ~ 100 |
| `SXK` | 速效钾 | mg/kg | float | 0 ~ 500 |
| `RZ` | 容重 | g/cm³ | float | 0.8 ~ 1.8 |

## 八、验收标准

### 8.1 命名规范验收

- [ ] 所有指标字段名符合第2章标准命名
- [ ] 衍生字段使用 `_LD`/`_QZ`/`_OD`/`_OL` 后缀
- [ ] 综合结果字段使用 `ZHQZ`/`GDZLDJ`/`PJFQ`

### 8.2 接口规范验收

- [ ] 输入接受标准 CSV 格式（3.1节模板）
- [ ] 输出符合标准 CSV 格式（3.2节模板）
- [ ] 提供 Python 函数调用接口（非交互式）
- [ ] 接口签名符合第4章要求

### 8.3 功能验收

- [ ] 模型C障碍度字段不覆盖原始值（C-1修复）
- [ ] 权重和阈值可通过配置文件调整
- [ ] 区域编码使用标准 `PJFQ` 字段
- [ ] 模型间无功能重叠（质量评价仅由模型C负责）

### 8.4 数据验收

- [ ] 提供标准测试数据集（≥10条记录）
- [ ] 提供预期输出用于结果比对
- [ ] 测试数据覆盖所有区域编码
- [ ] 测试数据包含边界值（如pH=3.5、pH=10.0）

### 8.5 运行验收

- [ ] 依赖清单完整，可一键安装
- [ ] 使用标准测试数据运行，输出与预期一致（误差 ≤ 0.001）
