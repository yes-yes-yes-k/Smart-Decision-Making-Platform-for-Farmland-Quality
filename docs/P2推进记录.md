# P2 后端推进记录

更新日期：2026-09-18
当前状态：**首版已实现，可进入前端联调**

## 点选与悬浮数据支撑

- `POST /api/v1/farmland-statistics/parcels/pick` 支持 `metric`，传入后只返回当前指标，未传时保持原有 8 指标响应。
- 支持 `toleranceMeters`，范围 0–50 米；优先返回精确覆盖地块，否则返回容差内最近地块。
- 响应增加 `hit.mode`、`distanceMeters` 和实际容差。
- 增加 5 秒、最多 512 项的进程内短时缓存。
- 点选按用户限制为 120 次/分钟，超限返回 HTTP 429；前端仍应优先做本地拾取和防抖。

## 当前视口轻量地块接口

- 新增 `GET /api/v1/farmland-statistics/parcels/viewport`。
- 必填 `bbox` 和 `metric`；支持 `geometry=centroid|simplified|none`、`zoom` 和 `limit`。
- 单次最多 5000 个地块，返回 `truncated` 供客户端继续缩小范围。
- 每个要素包含地块 ID、当前指标值、等级、颜色、来源信息，以及质心或按 zoom 简化并裁剪后的几何。
- 视口接口按用户限制为 60 次/分钟。

## 数据质量与来源

- 5488 个地块已回填 43904 条指标来源元数据。
- 每项指标返回 `dataSource`、`measurementYear`、`isImputed`、`imputationMethod` 和 `qualityFlag`。
- 新增 `GET /api/v1/farmland-statistics/quality/audit`，审计结果缓存 5 分钟。
- 新增可重复执行的来源迁移脚本和 JSON/Markdown 审计脚本。
- 详细结论见《指标质量审计报告》。

## 性能与索引核验

本机开发库单次结果：

| 场景 | 结果 | 耗时 |
|---|---:|---:|
| 单指标点选，8 米容差 | 精确命中 | 0.0896 s |
| 小视口质心要素 | 5 个地块 | 0.0048 s |
| 5488 地块质量审计 | 8 项指标 | 0.3932 s |

`EXPLAIN` 显示点选和视口查询均使用 `idx_parcel_info_geom` GiST Index Scan。以上是功能联调数据，不代替部署环境并发压测。

相关指标、边界、统计、点选、视口和审计自动化测试共 62 项，全部通过；两项数据迁移重复 dry-run 候选数均为 0，OpenAPI JSON 校验通过。

## 后续事项

- 前端优先使用视口批量要素做本地悬浮拾取，避免逐次调用点选接口。
- 部署为多进程或多实例时，将进程内缓存和限流迁移至 Redis 等共享存储。
- 由数据提供方核实 `source_unverified` 指标的真实采样方式，并确认两项低变异厚度指标是否为区域回填或默认值。
