# M1：十篇真实文献证据对照闭环

日期：2026-10-30。M1隔离功能闭环已实现并验证；自动抽取覆盖很低，不构成抽取质量达标、生产上线或十万篇容量通过。

## 已交付

- 十篇来源按主题、长文、OCR混合、CAJ转换、PDF-in-CAJ和综述确定性登记；均来自既有合格公开论文，未按模型结果替换来源。
- 原件SHA256及全部1306个既有分块经过本地重解析核对，文本、顺序和页码一致。模型仅查看每篇8个任务相关分块，共80块，不宣称整篇抽取完成。
- 研究记录使用既有`SourceChunk`/`EvidenceReference`：字段值从原文选取，程序构建跨度；未知保持未知。同文献不同结果分开，不自动合并或汇总效应。
- 显式迁移的隔离研究存储、可独立的全文来源检索、带状态的可选图召回、JWT身份验证、逐块原文回看和待审记录对照。
- 单独提交的异步持久任务，支持取消、超时、租约重领和有限恢复；提交时、执行后及结果读取时重验来源、权限、候选状态及版本。
- 默认不启用新服务、不自动建表。现有应用已挂载同一产品蓝图；隔离试点使用轻量应用与同一蓝图的真实HTTP处理路径，不初始化原完整应用或部署监听服务。

27条不合格选择主要为摘录不在指定块中或出现多次而无法唯一定位。本轮保留原始响应和失败项，不调整原文、不把其他位置猜作模型选择、不补发语义纠正请求。产品展示明确报告每篇的有效记录、拒收选择和局部覆盖；无匹配记录不等于没有效应。

因此本轮证明的是产品能够接收真实来源、检索、保留合法待审记录、输出有据对照并处理失败/失效，不证明自动抽取已能覆盖所需知识。后续改进应针对实际任务风险；不以再建金标或不断扩大模型调用作为默认下一步。

## 验证证据

`artifacts/knowledge_platform/evidence-m1-v1/product-pilot-v2.json`记录最终十篇产品HTTP路径。使用现有活动用户的身份信息，由隔离实例生成临时JWT，令牌未写入产物；每次来源检查只读当前PostgreSQL并重验原件字节哈希。试点写入仅发生在显式迁移的`runtime/product.sqlite3`。

组合对照由独立有限worker执行；在其提交前暂停该worker时，GET任务显示running，同步来源检索仍返回结果。相同请求与有效来源签名复用已完成结果。后台线程和CLI均已结束，没有部署常驻服务。

31项独立unittest覆盖：

- 构造/预览不建表，空库回滚不删除无关表，非空回滚拒绝破坏数据。
- 伪造摘录、跨文献字段、记录篡改及未经审核提升被拒绝；未知条件不标为匹配，同文不同结果不合并。
- 图后端不可用时原文检索继续；来源权限、内容版本、原件字节或分块快照变化时拒绝旧数据。
- JWT/活动身份、任务所有者隔离、审核角色；原文上下文要求当前内容版本。
- 取消与晚到提交的竞争、超时、过期租约与次数上限、新服务实例恢复持久排队。
- 完成结果在来源撤回或候选拒绝后失效，不返回旧内容。

这些故障回归在临时隔离数据上验证，不能冒称生产库发生过撤回或完成了AGE回滚。真实试点使用当前公开来源，故障注入与真实数据演示分开。

## 模型预算

用户明确授权M1独立50万token/20次尝试/并发2。实际计入 **35,395token、10次尝试、在途0**；剩余预算不自动用于其他批次。账本绑定授权哈希，不重置外部评测预算。原请求、来源及代码哈希均保留。

## 安装与可逆边界

显式预览/应用：

```powershell
.venv/Scripts/python.exe scripts/migrate_research_evidence.py --database artifacts/knowledge_platform/evidence-m1-v1/runtime/product.sqlite3
.venv/Scripts/python.exe scripts/migrate_research_evidence.py --database artifacts/knowledge_platform/evidence-m1-v1/runtime/product.sqlite3 --apply
```

CLI仅允许M1隔离runtime目录，不读取主库URI作为迁移目标。空库可用`--rollback-empty`删除研究表；非空数据必须保留并另定导出/迁移方案，不能直接drop。生产启用可通过移除显式配置回退为未配置状态，保留研究数据；本轮没有执行部署或设置`.env`。

有限消费与测试：

```powershell
.venv/Scripts/python.exe scripts/run_research_comparison_worker.py --database artifacts/knowledge_platform/evidence-m1-v1/runtime/product.sqlite3 --max-jobs 1
.venv/Scripts/python.exe -m unittest tests.test_research_evidence
```

独立unittest避开根pytest配置自动初始化完整应用的副作用。PostgreSQL研究存储方言虽有实现，本轮实际业务写入验证使用隔离SQLite，不认证其生产PG迁移或并发性能；PG在本轮仅承担只读当前来源核查。
